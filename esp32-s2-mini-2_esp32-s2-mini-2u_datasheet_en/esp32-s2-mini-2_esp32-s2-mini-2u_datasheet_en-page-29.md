9.2 Dimensions of External Antenna Connector

**Body Text:**
ESP32-S2-MINI-2U uses the third generation external antenna connector as shown in Figure 9-3 *Dimensions of External Antenna Connector*. This connector is compatible with the following connectors:

- W.FL Series connector from Hirose
- MHF III connector from I-PHIX
- AMMC connector from Amphenol

**Additional Text Below Diagrams and Annotations:**
The external antenna used for ESP32-S2-MINI-2U during certification testing is the third generation monopole antenna, with material code TFPD08H1006O011.
The module does not include an external antenna upon shipment. If needed, select a suitable external antenna based on the product’s usage environment and performance requirements.

It is recommended to select an antenna that meets the following requirements:
- 2.4 GHz & 5 GHz band
- 50 Ω impedance
