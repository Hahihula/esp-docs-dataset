```markdown
Register 37.12. PPA_BLEND_RGB_REG (0x0048)

PPA_BLEND1_RX_B   Configures the B channel value when the BLEND foreground layer is in A4/A8.
(R/W)

PPA_BLEND1_RX_G   Configures the G channel value when the BLEND foreground layer is in A4/A8.
(R/W)

PPA_BLEND1_RX_R   Configures the R channel value when the BLEND foreground layer is in A4/A8.
(R/W)
```

```markdown
Register 37.13. PPA_BLEND_FIX_PIXEL_REG (0x004C)

PPA_BLEND_TX_FIX_PIXEL   Configures the pixel in the BLEND image filling mode.
[31:24]: A, [23:16]:R, [15:8]: G, [7:0]: B.
(R/W)
```
