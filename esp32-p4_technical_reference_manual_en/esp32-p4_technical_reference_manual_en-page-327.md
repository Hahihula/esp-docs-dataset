Register 4.107. AXI_DMA_EXTR_MEM_START_ADDR_REG (0x0284)

AXI_DMA_ACCESS_EXTR_MEM_START_ADDR Configures the start address of the accessible external memory address space. (R/W)

Register 4.108. AXI_DMA_EXTR_MEM_END_ADDR_REG (0x0288)

AXI_DMA_ACCESS_EXTR_MEM_END_ADDR Configures the end address of the accessible external memory address space. (R/W)
