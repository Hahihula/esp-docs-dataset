## 15.5.3 Event Task Matrix

The system timer on ESP32-P4 supports the Event Task Matrix (ETM) function, which allows the system timer’s ETM tasks to be triggered by any peripherals’ ETM events, or system timer’s ETM events to trigger any peripherals’ ETM tasks. This section introduces the ETM tasks and events related to the system timer. For more information, please refer to Chapter 13 Event Task Matrix (ETM).

The system timer can generate the following ETM event:

*   SYSTIMER_EVT_CNT_CMPx: Indicates the alarm events generated by CMPx.

When SYSTIMER_ETM_EN is set to 1, the alarm events can trigger the ETM event.

## 15.5.4 Synchronization Operation

The frequency of the clock used for software configuration is different from that of the clock driving the timer counters and comparators. Therefore, synchronization is required for configuring some registers. The steps are as follows:

1.  Software writes specific values to configuration fields. See the first column in Table 15.5-3.
2.  Software writes 1 to corresponding bits to start synchronization. See the second column in Table 15.5-3.
