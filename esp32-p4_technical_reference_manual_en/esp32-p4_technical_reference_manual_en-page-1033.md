PMU_WAKEUP_CAUSE indicates the wake-up source. For the mapping between values and sources please refer to Table 14.4-1. (RO)

## Register 14.41. PMU_HP_CK_CNTL_REG (0x0154)

PMU_MODIFY_ICG_CNTL_WAIT Configures the wait time for modifying the functional module clock gating. The unit is LP_DYN_FAST_CLK. (R/W)

PMU_SWITCH_ICG_CNTL_WAIT Configures the wait time for switching the functional module clock gating. The unit is LP_DYN_FAST_CLK. (R/W)
