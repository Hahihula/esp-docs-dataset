```markdown
Register 19.19. PMS_DMA_AHB_PDMA_RMT_R_PMS_REG (0x0158)

PMS_DMA_AHB_PDMA_RMT_R_PMS   Configures GDMA-AHB permission to read 32 address ranges requested by RMT. Bit 0 corresponds to region0, and so on.
O: Disable read permission.
1: Enable read permission.
(R/W)
```

```markdown
Register 19.20. PMS_DMA_AHB_PDMA_RMT_W_PMS_REG (0x0170)

PMS_DMA_AHB_PDMA_RMT_W_PMS   Configures GDMA-AHB permission to write 32 address ranges requested by RMT. Bit 0 corresponds to region0, and so on.
O: Disable write permission.
1: Enable write permission.
(R/W)
```
