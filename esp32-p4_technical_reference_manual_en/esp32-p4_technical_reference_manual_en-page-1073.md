Register 15.6. SYSTIMER_UNITO_VALUE_LO_REG (0x0044)

SYSTIMER_TIMER_UNITO_VALUE_LO Represents UNITO read value, low 32 bits. (RO)

Register 15.7. SYSTIMER_UNITO_LOAD_REG (0x005C)

SYSTIMER_TIMER_UNITO_LOAD Configures whether to reload the value of UNITO, i.e., reloads
the values of SYSTIMER_TIMER_UNITO_VALUE_HI and SYSTIMER_TIMER_UNITO_VALUE_LO to
UNITO.
0: No effect
1: Reload the value of UNITO
(WT)
