```markdown
Register 4.125. AXI_DMA_OUT_DSCR_BF1_CHn_REG (n: 0-2) (0x0174+0x68*n)

AXI_DMA_OUTLINK_DSCR_BF1_CHn Represents the address of the previous transmit descriptor y-1 that is pre-read. (RO)
```

```markdown
Register 4.126. AXI_DMA_LINK_SWITCH_STATE_REG (0x02DC)

AXI_DMA_LINK_SWITCH_STATE_CHn Configures whether to switch the linked lists read by AXI DMA.
O: Not switch
1: Switch
(R/W)
```
