

```markdown
Register 4.109. AXI_DMA_IN_RESET_AVAIL_CHn_REG (n: 0-2) (0x028C+0x4*n)

AXI_DMA_IN_RESET_AVAIL_CHn Represents whether RX channel n can be reset.
0: Cannot be reset by software
1: Can be reset
(RO)
```

```markdown
Register 4.110. AXI_DMA_OUT_RESET_AVAIL_CHn_REG (n: 0-2) (0x0298+0x4*n)

AXI_DMA_OUT_RESET_AVAIL_CHn Represents whether TX channel n can be reset.
0: Cannot be reset by software
1: Can be reset
(RO)
```
