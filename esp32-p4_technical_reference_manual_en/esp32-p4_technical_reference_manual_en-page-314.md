Register 4.85. AXI_DMA_IN_CRC_FINAL_RESULT_CHn_REG (n: 0-2) (0x0054+0x68*n)

AXI_DMA_IN_CRC_FINAL_RESULT_CHn Represents the CRC result for RX channel n. (RO)

Register 4.86. AXI_DMA_RX_CRC_EN_ADDR_CHn_REG (n: 0-2) (0x005C+0x68*n)

AXI_DMA_RX_CRC_EN_ADDR_CHn Configures at which bit of the CRC result the AXI_DMA_RX_CRC_EN_WR_DATA_CHn_REG register targets for TX channel n. (R/W)
