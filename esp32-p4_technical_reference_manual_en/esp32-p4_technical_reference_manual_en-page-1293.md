Register 20.59. HP_SYSTEM_GMAC_CTRL1_REG (0x0150)

HP_SYSTEM_SYS_PTP_TIMESTAMP_L Represents the lower 32 bits of timestamp output from Ethernet MAC synchronized to clk_ptp_ref clock. (RO)

Register 20.60. HP_SYSTEM_GMAC_CTRL2_REG (0x0154)

HP_SYSTEM_SYS_PTP_TIMESTAMP_H Represents the upper 32 bits of timestamp output from Ethernet MAC synchronized to clk_ptp_ref clock. (RO)
