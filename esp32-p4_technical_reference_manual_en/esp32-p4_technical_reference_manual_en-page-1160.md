```markdown
Register 19.11. PMS_DMA_AHB_PDMA_I2S1_R_PMS_REG (0x0138)

PMS_DMA_AHB_PDMA_I2S1_R_PMS Configures GDMA-AHB permission to read 32 address ranges requested by I2S1. Bit 0 corresponds to region0, and so on.

0: Disable read permission.
1: Enable read permission.
(R/W)
```

```markdown
Register 19.12. PMS_DMA_AHB_PDMA_I2S1_W_PMS_REG (0x013C)

PMS_DMA_AHB_PDMA_I2S1_W_PMS Configures GDMA-AHB permission to write 32 address ranges requested by I2S1. Bit 0 corresponds to region0, and so on.

0: Disable write permission.
1: Enable write permission.
(R/W)
```
