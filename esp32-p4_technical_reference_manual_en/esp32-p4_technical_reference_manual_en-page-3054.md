

```markdown
Register 62.28. LPADC_MEAS2_MUX_REG (0x0034)

LPADC_SAR2_LP_FORCE Configures whether to disable HP ADC2 Controller to control SAR ADC2.
O: Do not disable HP ADC2 Controller.
1: Disable HP ADC2 Controller.
(R/W)
```

```markdown
Register 62.29. LPADC_ATTEN2_REG (0x0038)

LPADC_SAR2_ATTEN Configures the attenuation value for one-shot sampling of LP ADC2.

O: 0 dB
1: 2.5 dB
2: 6 dB
3: 12 dB
(R/W)
```
