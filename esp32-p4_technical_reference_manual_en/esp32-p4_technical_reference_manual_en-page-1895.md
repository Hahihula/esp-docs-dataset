Register 39.43. H264_BS_THRESHOLD_REG (0x00B4)

H264_BS_BUFFER_THRESHOLD Configures bitstream buffer overflow threshold. This value should be bigger than the encoded bytes of one 4x4 sub MB. (R/W)


Register 39.44. H264_SLICE_HEADER_BYTE0_REG (0x00B8)

H264_SLICE_BYTE_LSB Configures slice header low 32 bit. (R/W)


Register 39.45. H264_SLICE_HEADER_BYTE1_REG (0x00BC)

H264_SLICE_BYTE_MSB Configures slice header high 32 bit. (R/W)
