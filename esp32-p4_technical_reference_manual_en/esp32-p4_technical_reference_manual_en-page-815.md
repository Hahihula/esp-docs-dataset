Register 12.275. CORE1_INTR_STATUS_REG_1_REG (0x0204)

CORE1_INTR_STATUS_1 Represents the status of the interrupt sources from 32 ~ 63. Each bit corresponds to one interrupt source. (RO)

Register 12.276. CORE1_INTR_STATUS_REG_2_REG (0x0208)

CORE1_INTR_STATUS_2 Represents the status register for interrupt sources from 64 ~ 95. Each bit corresponds to one interrupt source. (RO)

Register 12.277. CORE1_INTR_STATUS_REG_3_REG (0x020C)

CORE1_INTR_STATUS_3 Represents the status of the interrupt sources from 96 ~ 127. Each bit corresponds to one interrupt source. (RO)
