

```markdown
Register 19.33. PMS_DMA_DMA2D_JPEG_PMS_R_REG (0x01A4)

PMS_DMA_DMA2D_JPEG_R_PMS Configures 2D-DMA permission to read 32 address ranges requested by JPEG. Bit 0 corresponds to region0, and so on.
O: Disable read permission.
1: Enable read permission.
(R/W)
```

```markdown
Register 19.34. PMS_DMA_DMA2D_JPEG_PMS_W_REG (0x01A8)

PMS_DMA_DMA2D_JPEG_W_PMS Configures 2D-DMA permission to write 32 address ranges requested by JPEG. Bit 0 corresponds to region0, and so on.
O: Disable write permission.
1: Enable write permission.
(R/W)
```
