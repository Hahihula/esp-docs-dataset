Register 53.15. TWAI_TX_ERR_CNT_REG (0x003C)

TWAI_TX_ERR_CNT The TX error counter register, which reflects value changes in transmission status. (R/W)


Register 53.16. TWAI_RX_MESSAGE_COUNTER_REG (0x0074)
