```markdown
Register 19.9. PMS_DMA_AHB_PDMA_I2SO_R_PMS_REG (0x0130)

PMS_DMA_AHB_PDMA_I2SO_R_PMS   Configures GDMA-AHB permission to read 32 address ranges requested by I2SO. Bit 0 corresponds to region0, and so on.
0: Disable read permission.
1: Enable read permission.
(R/W)
```

```markdown
Register 19.10. PMS_DMA_AHB_PDMA_I2SO_W_PMS_REG (0x0134)

PMS_DMA_AHB_PDMA_I2SO_W_PMS   Configures GDMA-AHB permission to write 32 address ranges requested by I2SO. Bit 0 corresponds to region0, and so on.
0: Disable write permission.
1: Enable write permission.
(R/W)
```
