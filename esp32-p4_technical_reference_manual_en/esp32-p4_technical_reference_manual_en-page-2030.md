Register 39.230. H264_DMA_IN_ERR_EOF_DES_ADDR_CHO_REG (0x052C)

H264_DMA_IN_ERR_EOF_DES_ADDR_CHO Represents the address of the inlink descriptor when there are errors during the current data reception. (RO)


Register 39.231. H264_DMA_IN_DSCR_CHO_REG (0x0530)

H264_DMA_INLINK_DSCR_CHO Represents the address of the next descriptor x+1 pointed by the current descriptor that is pre-read. (RO)


Register 39.232. H264_DMA_IN_DSCR_BFO_CHO_REG (0x0534)

H264_DMA_INLINK_DSCR_BFO_CHO Represents the address of the current descriptor x that is pre-read. (RO)
