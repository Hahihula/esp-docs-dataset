Register 4.91: AXI_DMA_OUT_PUSH_CHn_REG (n: 0-2) (0x0154+0x68*n)

AXI_DMA_OUTFIFO_WDATA_CHn   Represents the data that need to be pushed into AXI DMA TX FIFO. (R/W)

AXI_DMA_OUTFIFO_PUSH_CHn    Configures whether to push data into AXI DMA TX FIFO.
  0: Invalid. No effect
  1: Push
    (WT)
