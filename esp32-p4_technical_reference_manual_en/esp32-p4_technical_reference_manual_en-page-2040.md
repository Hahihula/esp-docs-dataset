

```markdown
Register 39.252. H264_DMA_IN_ERR_EOF_DES_ADDR_CH2_REG (0x072C)

H264_DMA_IN_ERR_EOF_DES_ADDR_CH2 Represents the address of the inlink descriptor when there are errors during the current data reception. (RO)
```

```markdown
Register 39.253. H264_DMA_IN_DSCR_CH2_REG (0x0730)

H264_DMA_INLINK_DSCR_CH2 Represents the address of the next descriptor x+1 pointed by the current descriptor that is pre-read. (RO)
```

```markdown
Register 39.254. H264_DMA_IN_DSCR_BFO_CH2_REG (0x0734)

H264_DMA_INLINK_DSCR_BFO_CH2 Represents the address of the current descriptor x that is pre-read. (RO)
```
