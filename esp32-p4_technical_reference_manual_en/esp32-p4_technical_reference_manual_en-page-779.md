All interrupts generated by the peripheral interrupt sources can be handled by HP CPU0 or HP CPU1. Users can configure HP CPU0 interrupt registers ("Core0 Interrupt Reg" module in Figure 12.3-1) to assign peripheral interrupt sources to HP CPU0, or configure HP CPU1 interrupt registers ("Core1 Interrupt Reg" module in Figure 12.3-1) to assign peripheral interrupt sources to HP CPU1. Peripheral interrupt sources can be mapped to both HP CPU0 and HP CPU1 at the same time, allowing both to receive the interrupts.

12.4 Functional Description

12.4.1 Peripheral Interrupt Sources

ESP32-P4 has 128 peripheral interrupt sources in total. Table 12.4-1 lists all these sources and their mapping/status registers.

*   Column "No.": Peripheral interrupt source number, which can be 0 ~ 82, 84 ~ 98, 100 ~ 111, 113 ~ 130 (83, 99 and 112 are reserved).
*   Column "Chapter": The chapter in which the interrupt source is described in detail.
*   Column "Interrupt Source": Name of the peripheral interrupt source.
*   Column "Interrupt Source Mapping Register": Registers used for routing the peripheral interrupt sources to HP CPU peripheral interrupts.
*   Column "Interrupt Status Register": Registers used for indicating the interrupt status of peripheral interrupt sources.

    -   Column "Interrupt Status Register - Bit": Bit position in status register, indicating the interrupt status.
    -   Column "Interrupt Status Register - Name": Name of status registers.
