Register 39.219. H264_DMA_OUT_DSCR_CH4_REG (0x042C)

H264_DMA_OUTLINK_DSCR_CH4 Represents the address of the next descriptor y+1 pointed by the current descriptor that is pre-read. (RO)

Register 39.220. H264_DMA_OUT_DSCR_BFO_CH4_REG (0x0430)

H264_DMA_OUTLINK_DSCR_BFO_CH4 Represents the address of the current descriptor y that is pre-read. (RO)

Register 39.221. H264_DMA_OUT_DSCR_BF1_CH4_REG (0x0434)

H264_DMA_OUTLINK_DSCR_BF1_CH4 Represents the address of the previous descriptor y-1 that is pre-read. (RO)
