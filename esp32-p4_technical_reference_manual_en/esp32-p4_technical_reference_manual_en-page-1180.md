Register 19.51. PMS_DMA_DMA2D_PPA_PMS_R_REG (0x0204)

PMS_DMA_DMA2D_PPA_R_PMS    Configures 2D-DMA permission to read 32 address ranges requested by PPA (Pixel-Processing Accelerator). Bit 0 corresponds to region0, and so on.
O: Disable read permission.
1: Enable read permission.
(R/W)

Register 19.52. PMS_DMA_DMA2D_PPA_PMS_W_REG (0x0208)

PMS_DMA_DMA2D_PPA_W_PMS    Configures 2D-DMA permission to write 32 address ranges requested by PPA. Bit 0 corresponds to region0, and so on.
O: Disable write permission.
1: Enable write permission.
(R/W)
