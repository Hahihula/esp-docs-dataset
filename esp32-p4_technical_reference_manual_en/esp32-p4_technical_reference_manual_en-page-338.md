Register 4.122. AXI_DMA_OUT_EOF_BFR_DES_ADDR_CHn_REG (n: 0-2) (0x0168+0x68*n)

AXI_DMA_OUT_EOF_BFR_DES_ADDR_CHn Represents the address of the transmit descriptor before the last transmit descriptor. (RO)

Register 4.123. AXI_DMA_OUT_DSCR_CHn_REG (n: 0-2) (0x016C+0x68*n)

AXI_DMA_OUTLINK_DSCR_CHn Represents the address of the next transmit descriptor y+1 pointed by the current transmit descriptor that is pre-read. (RO)

Register 4.124. AXI_DMA_OUT_DSCR_BFO_CHn_REG (n: 0-2) (0x0170+0x68*n)

AXI_DMA_OUTLINK_DSCR_BFO_CHn Represents the address of the current transmit descriptor y that is pre-read. (RO)
