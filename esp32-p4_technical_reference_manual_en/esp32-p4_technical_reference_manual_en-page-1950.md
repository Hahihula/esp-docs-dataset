Chapter 39 H264 Encoder

Register 39.115. H264_DMA_IN_CONF3_CH5_REG (0x0AOC)

H264_DMA_BLOCK_LENGTH_12LINE_CH5 Configures the number of bytes contained in a block
12line (R/W)

H264_DMA_BLOCK_LENGTH_4LINE_CH5 Configures the number of bytes contained in a block
4line (R/W)

Register 39.116. H264_DMA_IN_POP_CH5_REG (0x0A24)

H264_DMA_INFIFO_RDATA_CH5 Represents the data popped from DMA RX FIFO. (RO)

H264_DMA_INFIFO_POP_CH5 Configures whether to pop data from DMA RX FIFO.
0: No effect
1: Pop
(R/W/SC)
