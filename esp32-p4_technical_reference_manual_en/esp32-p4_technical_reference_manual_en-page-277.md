Register 4.22. AHB_DMA_OUT_CRC_FINAL_RESULT_CHn_REG (n: 0-2) (0x02C8+0x28*n)

AHB_DMA_OUT_CRC_FINAL_RESULT_CHn Represents the CRC result for TX channel n. (RO)

Register 4.23. AHB_DMA_TX_CRC_EN_WR_DATA_CHn_REG (n: 0-2) (0x02CC+0x28*n)

AHB_DMA_TX_CRC_EN_WR_DATA_CHn Configures whether to include each bit of the intermediate result in the CRC calculation matrix for TX channel n.
O: Not include
1: Include
(R/W)
