Register 6.58. DMA2D_IN_DSCR_BFO_CHn_REG (n: 0-2) (0x0534+0x100*n)

DMA2D_INLINK_DSCR_BFO_CHn   Represents the address of the current receive descriptor that is pre-read. (RO)

Register 6.59. DMA2D_IN_DSCR_BF1_CHn_REG (n: 0-2) (0x0538+0x100*n)

DMA2D_INLINK_DSCR_BF1_CHn   Represents the address of the previous receive descriptor that is pre-read. (RO)
