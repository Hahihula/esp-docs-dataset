Register 15.18. SYSTIMER_TARGET1_HI_REG (0x0024)

SYSTIMER_TIMER_TARGET1_HI Configures the alarm value to be loaded to COMP1, high 20 bits.
(R/W)


Register 15.19. SYSTIMER_TARGET1_LO_REG (0x0028)

SYSTIMER_TIMER_TARGET1_LO Configures the alarm value to be loaded to COMP1, low 32 bits.
(R/W)


Register 15.20. SYSTIMER_TARGET1_CONF_REG (0x0038)

SYSTIMER_TARGET1_PERIOD Configures COMP1 alarm period. (R/W)
SYSTIMER_TARGET1_PERIOD_MODE Selects the two alarm modes for COMP1. See details in SYS-TIMER_TARGETO_PERIOD_MODE. (R/W)
SYSTIMER_TARGET1_TIMER_UNIT_SEL Chooses the count value for comparison with COMP1. See details in SYSTIMER_TARGETO_TIMER_UNIT_SEL. (R/W)
