Register 39.110. H264_DMA_IN_LINK_ADDR_CH4_REG (0x0920)

H264_DMA_INLINK_ADDR_CH4   Configures the first inlink descriptor's address. (R/W)


Register 39.111. H264_DMA_IN_ARB_CH4_REG (0x0940)

H264_DMA_IN_ARB_TOKEN_NUM_CH4   Configures the maximum token count for the arbiter configuration. (R/W)

H264_DMA_EXTER_IN_ARB_PRIORITY_CH4   Configures the priority of external memory access for RX channel 4. (R/W)

H264_DMA_INTER_IN_ARB_PRIORITY_CH4   Configures the priority of internal memory access for RX channel 4. (R/W)
