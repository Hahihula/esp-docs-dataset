Chapter 39 H264 Encoder

Register 39.75. H264_DMA_OUT_ARB_CH2_REG (0x023C)

H264_DMA_OUT_ARB_TOKEN_NUM_CH2 Configures the maximum token count for the arbiter configuration. (R/W)

H264_DMA_INTER_OUT_ARB_PRIORITY_CH2 Configures the priority of internal memory access for TX channel 2.
