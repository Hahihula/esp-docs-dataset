Register 4.105. AXI_DMA_INTR_MEM_START_ADDR_REG (0x027C)

AXI_DMA_ACCESS_INTR_MEM_START_ADDR Configures the start address of the accessible internal memory address space. (R/W)


Register 4.106. AXI_DMA_INTR_MEM_END_ADDR_REG (0x0280)

AXI_DMA_ACCESS_INTR_MEM_END_ADDR Configures the end address of the accessible internal memory address space. (R/W)
