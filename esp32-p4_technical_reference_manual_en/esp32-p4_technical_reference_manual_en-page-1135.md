Register 18.12. RTC_TIMER_INT_ENA_REG (0x0030)

RTC_TIMER_OVERFLOW_ENA   Configure to enable the interrupt for 48-bit counter overflow. (R/W)
RTC_TIMER_MAIN_TIMER_INT_ENA   Configure to enable the interrupt for the RTC Timer reaching the target time 0. (R/W)

Register 18.13. RTC_TIMER_INT_CLR_REG (0x0034)

RTC_TIMER_OVERFLOW_CLR   Configure to clear the interrupt for 48-bit counter overflow. (WO)
RTC_TIMER_MAIN_TIMER_INT_CLR   Configure to clear the interrupt for the RTC Timer reaching the target time 0. (WO)
