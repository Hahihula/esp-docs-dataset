Register 39.188. H264_DMA_OUT_DSCR_CH1_REG (0x012C)

H264_DMA_OUTLINK_DSCR_CH1 Represents the address of the next descriptor y+1 pointed by the current descriptor that is pre-read. (RO)


Register 39.189. H264_DMA_OUT_DSCR_BFO_CH1_REG (0x0130)

H264_DMA_OUTLINK_DSCR_BFO_CH1 Represents the address of the current descriptor y that is pre-read. (RO)


Register 39.190. H264_DMA_OUT_DSCR_BF1_CH1_REG (0x0134)

H264_DMA_OUTLINK_DSCR_BF1_CH1 Represents the address of the previous descriptor y-1 that is pre-read. (RO)
