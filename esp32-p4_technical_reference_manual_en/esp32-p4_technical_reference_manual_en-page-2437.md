Register 44.65. LP_I2C_COMD7_REG (0x0074)

LP_I2C_COMMAND7 Configures command 7. See details in I2C_CMD0_REG[13:0]. (R/W)
LP_I2C_COMMAND7_DONE Represents whether command 7 is done in I2C Master mode.
    0: Not done
    1: Done
    (R/W/SS)

Register 44.66. LP_I2C_DATE_DATE_REG (0x00F8)

LP_I2C_DATE Version control register. (R/W)

Register 44.67. LP_I2C_TXFIFO_START_ADDR_REG (0x0100)

LP_I2C_TXFIFO_START_ADDR Represents the I2C txfifo first address. (HRO)
