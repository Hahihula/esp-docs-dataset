Register 35.23. JPEG_DHT_TOTLEN_DC1_REG (0x0068)

JPEG_DHT_TOTLEN_DC1   Configures the number of codeword with a codeword length of 1 to 16 bits for DC1 Huffman table in FIFO mode. (HRO)

Register 35.24. JPEG_DHT_VAL_DC1_REG (0x006C)

JPEG_DHT_VAL_DC1   Configures the symbols corresponding to the decoded codeword for DC1 Huffman table in FIFO mode. (HRO)

Register 35.25. JPEG_DHT_TOTLEN_AC1_REG (0x0070)

JPEG_DHT_TOTLEN_AC1   Configures the number of codeword with a codeword length of 1 to 16 bits for AC1 Huffman table in FIFO mode. (HRO)
