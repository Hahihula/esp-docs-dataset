Interrupt signal H264_REG_INT can be generated by the following internal interrupt sources:

*   H264_DMA_MOVE_2MB_LINE_DONE_INT: When H264_DMA completes moving the reference pictures of two MB rows from external memory to internal memory, the interrupt is triggered.
*   H264_FRAME_DONE_INT: When ENC_CORE finishes compressing and encoding a frame of video, the interrupt is triggered.
*   H264_REC_READY_INT: When ENC_CORE writes the deblocking filter result (i.e., the reference picture) of H264_x_REC_READY_TRIGGER_MB_LINES lines of MBs to the external memory, the interrupt is triggered. x can be A or B, indicating the register corresponds to video sequence A or B.
*   H264_DB_TMP_READY_INT: When ENC_CORE writes the deblocking filter intermediate data of H264_x_DB_TMP_READY_TRIGGER_MB_NUM MBs to the internal memory, the interrupt is triggered. x can be A or B indicating the register corresponds to video sequence A or B.

The above interrupt sources can only be triggered when the interrupt enable register XXX_ENA is set to 1. Write 1 to XXX_CLR will clear the interrupt (XXX is the interrupt source name).

The H264_DMA_IN_CHx_INT (x is 0 ~ 5) signals are generated by the following interrupt sources:

*   H264_DMA_IN_DONE_CHx_INT: Triggered when all data corresponding to a receive descriptor has been received via RX channel x (x is 0 ~ 5).
*   H264_DMA_IN_SUC_EOF_CHn_INT: Triggered when the suc_eof bit in a receive descriptor is 1 and the data corresponding to this receive descriptor has been received (i.e. when the data frame or packet corresponding to an inlink has been received) via RX channel x (x is 0 ~ 5).
*   H264_DMA_IN_ERR_EOF_CHx_INT: Triggered when an error is detected in the data frame or packet received via RX channel x (x is 0 ~ 4).
*   H264_DMA_IN_DSCR_EMPTY_CHx_INT: Triggered when the size of the buffer pointed by receive descriptors is smaller than the length of data to be received via RX channel x (x is 0 ~ 4).
*   H264_DMA_IN_DSCR_ERR_CHx_INT: Triggered when a receive descriptor on RX channel x (x is 0 ~ 4) fails any of the two descriptor checks.
*   H264_DMA_INFIFO_OVF_L1_CHx_INT: Triggered when the L1 RX FIFO of RX channel x (x is 0 ~ 5) overflows.
*   H264_DMA_INFIFO_OVF_L2_CHx_INT: Triggered when the L2 RX FIFO of RX channel x (x is 0 ~ 4) overflows.
*   H264_DMA_INFIFO_UDF_L1_CHx_INT: Triggered when the L1 RX FIFO of RX channel x (x is 0 ~ 5) underflows.
*   H264_DMA_INFIFO_UDF_L2_CHx_INT: Triggered when the L2 RX FIFO of RX channel x (x is 0 ~ 4) underflows.
*   H264_DMA_IN_DSCR_TASK_OVF_CHx_INT: Triggered when descriptor ready task FIFO of RX channel x (x is 0 ~ 4) overflows.
*   H264_DMA_FETCH_MB_COL_CNT_OVF_CHx_INT: Triggered when fetch MB columns cnt of RX channel x (x is 5) overflows.
