Register 39.241. H264_DMA_IN_ERR_EOF_DES_ADDR_CH1_REG (0x062C)

H264_DMA_IN_ERR_EOF_DES_ADDR_CH1 Represents the address of the inlink descriptor when there are errors during the current data reception. (RO)


Register 39.242. H264_DMA_IN_DSCR_CH1_REG (0x0630)

H264_DMA_INLINK_DSCR_CH1 Represents the address of the next descriptor x+1 pointed by the current descriptor that is pre-read. (RO)


Register 39.243. H264_DMA_IN_DSCR_BFO_CH1_REG (0x0634)

H264_DMA_INLINK_DSCR_BFO_CH1 Represents the address of the current descriptor x that is pre-read. (RO)
