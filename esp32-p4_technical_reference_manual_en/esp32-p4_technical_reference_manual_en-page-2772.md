Register 54.39. SDHOST_TBBCNT_REG (0x0060)

SDHOST_TBBCNT_REG Represents the number of bytes transferred between Host/DMA memory and BIU FIFO. (RO)


Register 54.40. SDHOST_DSCADDR_REG (0x0094)

SDHOST_DSCADDR_REG Represents the Descriptor Address Pointer, points to the start address of current descriptor read by DMA. (RO)


Register 54.41. SDHOST_BUFADDR_REG (0x0098)

SDHOST_BUFADDR_REG Represents the Buffer Address Pointer, points to the current Data Buffer Address being accessed by the DMA. (RO)
