Register 4.32. AHB_DMA_IN_CRC_FINAL_RESULT_CHn_REG (n: 0-2) (0x0340+0x28*n)

AHB_DMA_IN_CRC_FINAL_RESULT_CHn Represents the CRC result for RX channel n. (RO)

Register 4.33. AHB_DMA_RX_CRC_EN_WR_DATA_CHn_REG (n: 0-2) (0x0344+0x28*n)

AHB_DMA_RX_CRC_EN_WR_DATA_CHn Configures whether to include each bit of the intermediate result in the CRC calculation matrix for RX channel n.
O: Not include
1: Include
(R/W)
