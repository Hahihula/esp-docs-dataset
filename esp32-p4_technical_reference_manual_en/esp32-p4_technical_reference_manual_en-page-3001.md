Register 6016. LP_ANA_TOUCH_WORK_MEAS_NUM_REG (0x010C)

| Bit | Description                                                                 |
|-----|-----------------------------------------------------------------------------|
| 31  | (reserved)                                                                  |
| 30  | LP_ANA_TOUCH_MEAS_NUM2                                                     |
| 29  |                                                                             |
| 20  | LP_ANA_TOUCH_MEAS_NUM1                                                     |
| 19  |                                                                             |
| 10  | LP_ANA_TOUCH_MEAS_NUM0                                                     |
| 9   |                                                                             |
| 0   | Reset                                                                      |

LP_ANA_TOUCH_MEAS_NUM2 Configures the number of measurements for sampling frequency mode 2 in normal operation. (R/W)

LP_ANA_TOUCH_MEAS_NUM1 Configures the number of measurements for sampling frequency mode 1 in normal operation. (R/W)

LP_ANA_TOUCH_MEAS_NUM0 Configures the number of measurements for sampling frequency mode 0 in normal operation.(R/W)
