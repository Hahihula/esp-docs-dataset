Register 6.28. DMA2D_IN_COLOR_PARAM3_CHO_REG (0x0560)

DMA2D_IN_COLOR_PARAM_M1_CHO Configures the coefficient C and D for the middle byte of the input of color space conversion's second stage for RX channel 0. (R/W)

Register 6.29. DMA2D_IN_COLOR_PARAM4_CHO_REG (0x0564)

DMA2D_IN_COLOR_PARAM_LO_CHO Configures the coefficient A and B for the least significant byte of the input of color space conversion's second stage for RX channel 0. (R/W)

Register 6.30. DMA2D_IN_COLOR_PARAM5_CHO_REG (0x0568)

DMA2D_IN_COLOR_PARAM_L1_CHO Configures the coefficient C and D for the least significant byte of the input of color space conversion's second stage for RX channel 0. (R/W)
