```markdown
Register 19.55. PMS_DMA_AHB_PDMA_DUMMY_R_PMS_REG (0x0214)

PMS_DMA_AHB_PDMA_DUMMY_R_PMS Configures GDMA-AHB permission to read 32 address ranges requested by Dummy. Bit 0 corresponds to region0, and so on.

O: Disable read permission.
1: Enable read permission.
(R/W)
```

```markdown
Register 19.56. PMS_DMA_AHB_PDMA_DUMMY_W_PMS_REG (0x0218)

PMS_DMA_AHB_PDMA_DUMMY_W_PMS Configures GDMA-AHB permission to write 32 address ranges requested by Dummy. Bit 0 corresponds to region0, and so on.

O: Disable write permission.
1: Enable write permission.
(R/W)
```
