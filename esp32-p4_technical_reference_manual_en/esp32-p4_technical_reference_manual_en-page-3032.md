## 62.5.11 HP ADC GDMA Support

When HP ADC converts data on multiple channels, it is necessary to enable GDMA so that the data can be transferred to memory continuously.

GDMA support is triggered by the timer in the HP ADCx controllers. Users can switch the GDMA data path to the HP ADC controller by configuring ADC_APB_ADC_TRANS. For specific GDMA configuration, please refer to Chapter 4 GDMA Controller (GDMA-AHB, GDMA-AXI).

The HP ADC eventually passes 32-bit data to GDMA. The data format is shown in Figure 62.5-9.
