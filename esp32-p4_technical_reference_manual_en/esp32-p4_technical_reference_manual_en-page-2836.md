Write 1 to `interrupt_source_name` CLCR will clear the interrupt.\n\n**Note:**\nFor definitions of interrupt, interrupt signal, interrupt source, and their correlations, please refer to Chapter 12 Interrupt Matrix > Section 12.2 Interrupt Terminology in ESP32-P4.\n\nEach interrupt source can be configured by a common set of registers that are described in Section Interrupt Configuration Registers.
