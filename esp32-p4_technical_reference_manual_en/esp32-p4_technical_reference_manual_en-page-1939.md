Register 39.100. H264_DMA_IN_LINK_ADDR_CH2_REG (0x0720)

H264_DMA_INLINK_ADDR_CH2   Configures the first inlink descriptor's address. (R/W)


Register 39.101. H264_DMA_IN_ARB_CH2_REG (0x0740)

H264_DMA_IN_ARB_TOKEN_NUM_CH2   Configures the maximum token count for the arbiter configuration. (R/W)

H264_DMA_INTER_IN_ARB_PRIORITY_CH2   Configures the priority of internal memory access for RX channel 2. (R/W)
