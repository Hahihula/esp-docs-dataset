Register 39.261. H264_DMA_IN_STATE_CH3_REG (0x0824)

H264_DMA_IN_DSCR_ADDR_CH3 Represents the current inlink descriptor's address for RX channel 3. (RO)

H264_DMA_IN_DSCR_STATE_CH3 Represents the current state of the descriptor state machine for RX channel 3. (RO)

H264_DMA_IN_STATE_CH3 Represents the current control module state machine state for RX channel 3. (RO)

H264_DMA_IN_RESET_AVAIL_CH3 Represents whether it is safe to reset the channel.
0: Unsafe
1: Safe
(RO)

Register 39.262. H264_DMA_IN_SUC_EOF_DES_ADDR_CH3_REG (0x0828)

H264_DMA_IN_SUC_EOF_DES_ADDR_CH3 Represents the address of the inlink descriptor when the EOF bit in this descriptor is 1. (RO)
