Register 62.6. ADC_SAR1_PATT_TAB3_REG (0x0020)

ADC_SAR1_PATT_TAB3   Configures entries 8 ~ 11 for HP ADC FSM1. Each entry is 6-bit wide. See Section 62.5.6 HP ADC Pattern Table. (R/W)

Register 62.7. ADC_SAR1_PATT_TAB4_REG (0x0024)

ADC_SAR1_PATT_TAB4   Configures entries 12 ~ 15 for HP ADC FSM1. Each entry is 6-bit wide. See Section 62.5.6 HP ADC Pattern Table. (R/W)

Register 62.8. ADC_SAR2_PATT_TAB1_REG (0x0028)

ADC_SAR2_PATT_TAB1   Configures entries 0 ~ 3 for HP ADC FSM2. Each entry is 6-bit wide. See Section 62.5.6 HP ADC Pattern Table. (R/W)
