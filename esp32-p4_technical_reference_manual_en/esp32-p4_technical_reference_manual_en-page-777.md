

# Chapter 12 Interrupt Matrix

## 12.1 Overview

The interrupt matrix embedded in ESP32-P4 independently routes peripheral interrupt sources to the ESP-RISC-V CPU's peripheral interrupts to timely inform HP CPU0 or HP CPU1 to process the coming interrupts.

Peripheral interrupt sources must be routed to HP CPU0 or HP CPU1 through the interrupt matrix for the following reasons:

*   Each HP CPU has 32 interrupt inputs, but the ESP32-P4 provides 128 peripheral interrupt sources. To connect all sources to the CPUs, the interrupt matrix is required.
*   The interrupt matrix allows a single peripheral interrupt source to be mapped to any HP CPU0 or HP CPU1 interrupt input, depending on application requirements.

**Note:**
This chapter focuses on how to map peripheral interrupt sources to HP CPU0/HP CPU1 interrupts. For more details about interrupt configuration, interrupt vectors, and interrupt handling operations recommended by the ISA, please refer to Chapter 1 *High-Performance CPU*.

## 12.2 Interrupt Terminology in ESP32-P4

The following terms related to interrupts are defined in the context of the *ESP32-P4 Technical Reference Manual* to help readers better understand this document:

### 12.2.1 Interrupt

An interrupt is an event or condition that temporarily suspends the CPU's current execution to execute an interrupt service routine (ISR). This mechanism enables the CPU to respond immediately to important events.

The *ESP32-P4 Technical Reference Manual* uses the term "interrupt" in a broader sense to refer to both interrupt signal and interrupt source.

### 12.2.2 Interrupt Signal/Interrupt Source

Both interrupt signal and interrupt source describe the same signal from different points in the system.

From the perspective of peripherals, interrupt signals are generated by the peripheral's internal interrupt sources and are sent to the interrupt matrix.
