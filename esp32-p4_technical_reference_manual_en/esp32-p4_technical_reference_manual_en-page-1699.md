Register 36.51. ISP_SHARP_FILTER2_REG (0x0100)
```

| Bit | Description |
|-----|-------------|
| 31  | (reserved) |
| 15  | ISP_SHARP_FILTER_COE22 |
| 10  | ISP_SHARP_FILTER_COE21 |
| 5   | ISP_SHARP_FILTER_COE20 |
| 4   | Reset |

- **ISP_SHARP_FILTER_COE20** Configures the value of coordinate 20 in the low-pass filter template of the sharpen module. (R/W)
- **ISP_SHARP_FILTER_COE21** Configures the value of coordinate 21 in the low-pass filter template of the sharpen module. (R/W)
- **ISP_SHARP_FILTER_COE22** Configures the value of coordinate 22 in the low-pass filter template of the sharpen module. (R/W)
