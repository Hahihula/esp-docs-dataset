Register 6.34. DMA2D_INTR_MEM_END_ADDR_REG (0x0A0C)

DMA2D_ACCESS_INTR_MEM_END_ADDR   Configures the end address of the accessible internal address space. Accessing an address beyond this range will result in a descriptor error. (R/W)

Register 6.35. DMA2D_EXTR_MEM_START_ADDR_REG (0x0A10)

DMA2D_ACCESS_EXTR_MEM_START_ADDR   Configures the start address of the accessible external address space. (R/W)
