Register 4.28. AHB_DMA_TX_ARB_WEIGH_OPT_DIR_CHn_REG (n: 0-2) (0x02E0+0x28*n)

AHB_DMA_TX_ARB_WEIGH_OPT_DIR_CHn Configures whether to enable weight optimization for TX channel n.
O: Enable
1: Disable (R/W)

Register 4.29. AHB_DMA_IN_CRC_INIT_DATA_CHn_REG (n: 0-2) (0x0334+0x28*n)

AHB_DMA_IN_CRC_INIT_DATA_CHn Configures the CRC initial value for RX channel n. (R/W)
