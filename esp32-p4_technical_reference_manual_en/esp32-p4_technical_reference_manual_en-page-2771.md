

```markdown
Register 54.36. SDHOST_CDETECT_REG (0x0050)

SDHOST_CARD_DETECT_N | Represents value on sdhost_card_detect_n input ports. One bit per card. Bit[0] corresponds to card[0]. (RO)
```

```markdown
Register 54.37. SDHOST_WRTPRT_REG (0x0054)

SDHOST_WRITE_PROTECT | Represents value on sdhost_card_write_prot input ports, one bit per card. Bit[0] corresponds to card[0]. (RO)
```

```markdown
Register 54.38. SDHOST_TCBCNT_REG (0x005C)

SDHOST_TCBCNT_REG | Represents the number of bytes transferred by the CIU unit to the card. (RO)
```
