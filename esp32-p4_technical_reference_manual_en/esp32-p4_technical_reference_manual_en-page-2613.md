| Bits | Name                                       | Description                                                                                                                                                                                                                                                                       |
|------|---------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [7]  | IP Checksum Error (Type1), or Giant Frame   | When the Advanced Timestamp feature is present, and when this bit set, it indicates that a snapshot of the Timestamp is written in descriptor word 6 (RDES6) and 7 (RDES7). This is valid only when the Last Descriptor bit (RDESO[8]) is set.<br>When IP Checksum Engine (Type 1) is selected, this bit, if set, indicates one of the following:<ul><li>The 16-bit IPv4 header checksum calculated by the core did not match the received checksum bytes.</li><li>The header checksum checking is bypassed for non-IPv4 frames.</li></ul>Otherwise, this bit, when set, indicates the Giant Frame Status. When normal frame processing is enabled, Giant frames are larger than 1,518 bytes (or 1,522 bytes for VLAN or 2,000 bytes when ASS2KP is set). When Jumbo Frame processing is enabled, Giant frames are larger than 9,018 bytes (or 9,022 bytes for VLAN). |
| [6]  | LC: Late Collision                          | When set, this bit indicates that a late collision has occurred while receiving the frame in the half-duplex mode.                                                                                                                                                                   |
| [5]  | FT: Frame Type                              | When set, this bit indicates that the Receive Frame is an Ethernet-type frame (the LT field is greater than, or equal to, 1,536 bytes).<br>When reset, it indicates that the received frame is an IEEE 802.3 frame. This bit is not valid for Runt frames which are less than 14 bytes. |
| [4]  | RWT: Receive Watchdog Timeout               | When set, this bit indicates that the Receive Watchdog Timer has expired while receiving the current frame and the current frame is truncated after the Watchdog Timeout.                                                                                                               |
| [3]  | RE: Receive Error                           | When set, this bit indicates that the MII_RXER signal is asserted while MII_RXDV is asserted during frame reception.                                                                                                                                                                  |
| [2]  | DE: Dribble Bit Errors                      | When set, this bit indicates that the received frame has a non-integer multiple of bytes (odd nibbles). This bit is valid only in the MII Mode.                                                                                                                                         |
| [1]  | CE: CRC Error                               | When set, this bit indicates that a Cyclic Redundancy Check (CRC) Error occurred on the received frame. This field is valid only when the Last Descriptor (RDESO[8]) is set.                                                                                                                 |
