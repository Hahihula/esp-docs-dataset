Register 39.177. H264_DMA_OUT_DSCR_CHO_REG (0x002C)

H264_DMA_OUTLINK_DSCR_CHO    Represents the address of the next descriptor y+1 pointed by the current descriptor that is pre-read. (RO)


Register 39.178. H264_DMA_OUT_DSCR_BFO_CHO_REG (0x0030)

H264_DMA_OUTLINK_DSCR_BFO_CHO    Represents the address of the current descriptor y that is pre-read. (RO)


Register 39.179. H264_DMA_OUT_DSCR_BF1_CHO_REG (0x0034)

H264_DMA_OUTLINK_DSCR_BF1_CHO    Represents the address of the previous descriptor y-1 that is pre-read. (RO)
