

# Chapter 5 VDMA Controller (VDMA)

## 5.9 Registers

The addresses in this section are relative to the VDMA base address provided in Table 7.3-2 in Chapter 7 *System and Memory*.

For how to program reserved fields, please refer to Section *Programming Reserved Register Field*.

### Register 5.1. DMAC_IDO_REG (0x0000)

DMAC_DMAC_ID Represents VDMA ID number. (RO)

### Register 5.2. DMAC_COMPVERO_REG (0x0008)

DMAC_DMAC_COMPVER Represents VDMA version number. (RO)
