```markdown
Register 39.263. H264_DMA_IN_ERR_EOF_DES_ADDR_CH3_REG (0x082C)

H264_DMA_IN_ERR_EOF_DES_ADDR_CH3 Represents the address of the inlink descriptor when there are errors during the current data reception. (RO)
```

```markdown
Register 39.264. H264_DMA_IN_DSCR_CH3_REG (0x0830)

H264_DMA_INLINK_DSCR_CH3 Represents the address of the next descriptor x+1 pointed by the current descriptor that is pre-read. (RO)
```

```markdown
Register 39.265. H264_DMA_IN_DSCR_BFO_CH3_REG (0x0834)

H264_DMA_INLINK_DSCR_BFO_CH3 Represents the address of the current descriptor x that is pre-read. (RO)
```
