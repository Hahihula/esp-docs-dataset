Register 39.274. H264_DMA_IN_ERR_EOF_DES_ADDR_CH4_REG (0x092C)

H264_DMA_IN_ERR_EOF_DES_ADDR_CH4 Represents the address of the inlink descriptor when there are errors during the current data reception. (RO)


Register 39.275. H264_DMA_IN_DSCR_CH4_REG (0x0930)

H264_DMA_INLINK_DSCR_CH4 Represents the address of the next descriptor x+1 pointed by the current descriptor that is pre-read. (RO)


Register 39.276. H264_DMA_IN_DSCR_BFO_CH4_REG (0x0934)

H264_DMA_INLINK_DSCR_BFO_CH4 Represents the address of the current descriptor x that is pre-read. (RO)
