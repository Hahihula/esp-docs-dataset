Register 42.66. LP_UART_DATE_REG (0x008C)

LP_UART_DATE    Version control register. (R/W)


Register 42.67. LP_UART_REG_UPDATE_REG (0x0098)

LP_UART_REG_UPDATE   Configures whether or not to synchronize registers.
O: Not synchronize
1: Synchronize
(R/W/SC)


Register 42.68. LP_UART_ID_REG (0x009C)

LP_UART_ID    Configures the LP UART ID. (R/W)
