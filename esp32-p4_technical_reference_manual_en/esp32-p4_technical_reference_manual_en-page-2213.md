Data Flow Control in GP-SPI as Master**\n\nFigure 43.5-3 shows the data flow of GP-SPI as master. Its control logic is as follows:\n\n- RX data: data bits in SPI2/SPI3 bus is captured by Timing Module, converted into bytes by `spi_mst_din_ctrl` module, then buffered in `spi_rx_afifo`, and finally stored in corresponding addresses according to the transfer types.\n  - CPU-controlled transfer: the data is stored to registers `SPI_W0_REG`~`SPI_W15_REG`.\n  - DMA-controlled transfer: the data is stored to DMA RX buffer.\n- TX data: the TX data is from corresponding addresses according to transfer modes and is saved to `buf_tx_afifo`.\n  - CPU-controlled transfer: TX data is from `SPI_W0_REG`~`SPI_W15_REG`.\n  - DMA-controlled transfer: TX data is from DMA TX buffer.\nThe data in `buf_tx_afifo` is sent out to Timing Module in 1/2/4/(8)-bit modes, controlled by GP-SPI state machine. The Timing Module can be used for timing compensation. For more information, see Section 43.8.\n```
