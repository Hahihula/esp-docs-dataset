Register 9.58. GPIO_EXT_ETM_TASK_P9_CFG_REG (0x00C4)

GPIO_EXT_ETM_TASK_GPIO_EN (n: 36 - 39) Configures whether or not to enable GPIOn to re-
sponse ETM task.
O: Not enable
1: Enable
(R/W)

GPIO_EXT_ETM_TASK_GPIO_SEL (n: 36 - 39) Configures to select an ETM task channel for
GPIOn.
O: Select channel 0
1: Select channel 1
......
7: Select channel 7
(R/W)
