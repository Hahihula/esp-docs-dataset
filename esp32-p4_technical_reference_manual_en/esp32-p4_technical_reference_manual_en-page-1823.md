```markdown
Register 38.8. LCD_CAM_LCD_FIRST_CMD_VAL_REG (0x0028)

LCD_CAM_LCD_FIRST_CMD_VALUE Configures the value of the transmitted command when the LCD module is in the first cycle of the CMD phase. (R/W)
```

```markdown
Register 38.9. LCD_CAM_LCD_LATTER_CMD_VAL_REG (0x002C)

LCD_CAM_LCD_LATTER_CMD_VALUE Configures the value of the transmitted command when the LCD module is in the second cycle of the CMD phase. (R/W)
```
