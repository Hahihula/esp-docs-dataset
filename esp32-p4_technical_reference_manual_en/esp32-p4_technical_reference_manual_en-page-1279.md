Chapter 20 System Registers (SYSREG)

Register 20.39. HP_SYSTEM_HP_USB2OTG_MEM_CTRL_REG (0x00F8)

HP_SYSTEM_USB2O_MEM_CLK_FORCE_ON Configures whether or not to force on the memory clock in USB OTGHS.
- 0: Disable
- 1: Enable
(R/W)

Register 20.40. HP_SYSTEM_HP_SPM_PARITY_INT_RECORD_REG (0x010C)

HP_SYSTEM_HP_SPM_PARITY_ERR_INT_ADDR Records the address when HP_SPM_PARITY_ERR_INT occurs. (RO)
