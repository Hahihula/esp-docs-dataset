57.6 Registers

The addresses in this section are relative to Remote Control Peripheral base address provided in Table 7.3-2 in Chapter 7 System and Memory.

For how to program reserved fields, please refer to Section Programming Reserved Register Field.

Register 57.1. RMT_CHnDATA_REG (n: 0-3) (0x0000+0x4*n)

RMT_CHnDATA

RMT_CHnDATA Read and write data for channel n via APB FIFO. (HRO)
