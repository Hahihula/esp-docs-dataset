Register 62.9. ADC_SAR2_PATT_TAB2_REG (0x002C)

ADC_SAR2_PATT_TAB2   Configures entries 4 ~ 7 for HP ADC FSM2. Each entry is 6-bit wide. See Section 62.5.6 HP ADC Pattern Table. (R/W)


Register 62.10. ADC_SAR2_PATT_TAB3_REG (0x0030)

ADC_SAR2_PATT_TAB3   Configures entries 8 ~ 11 for HP ADC FSM2. Each entry is 6-bit wide. See Section 62.5.6 HP ADC Pattern Table. (R/W)


Register 62.11. ADC_SAR2_PATT_TAB4_REG (0x0034)

ADC_SAR2_PATT_TAB4   Configures entries 12 ~ 15 for HP ADC FSM2. Each entry is 6-bit wide. See Section 62.5.6 HP ADC Pattern Table. (R/W)
