Register 35.20. JPEG_DHT_VAL_DCO_REG (0x005C)

JPEG_DHT_VAL_DCO   Configures the symbols corresponding to the decoded codeword for DCO Huffman table in FIFO mode. (HRO)

Register 35.21. JPEG_DHT_TOTLEN_ACO_REG (0x0060)

JPEG_DHT_TOTLEN_ACO   Configures the number of codeword with a codeword length of 1 to 16 bits for ACO Huffman table in FIFO mode. (HRO)

Register 35.22. JPEG_DHT_VAL_ACO_REG (0x0064)

JPEG_DHT_VAL_ACO   Configures the symbols corresponding to the decoded codeword for ACO Huffman table in FIFO mode. (HRO)
