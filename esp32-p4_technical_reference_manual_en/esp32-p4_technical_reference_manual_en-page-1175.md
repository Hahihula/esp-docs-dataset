```markdown
Register 19.41. PMS_DMA_USBOTG11_PMS_R_REG (0x01C4)

PMS_DMA_USBOTG11_R_PMS Configures read permission for full-speed USB 2.0 OTG to access 32 address ranges. Bit 0 corresponds to region0, and so on.
0: Disable read permission.
1: Enable read permission.
(R/W)
```

```markdown
Register 19.42. PMS_DMA_USBOTG11_PMS_W_REG (0x01C8)

PMS_DMA_USBOTG11_W_PMS Configures write permission for full-speed USB 2.0 OTG to access 32 address ranges. Bit 0 corresponds to region0, and so on.
0: Disable write permission.
1: Enable write permission.
(R/W)
```
