Register 39.255. H264_DMA_IN_DSCR_BF1_CH2_REG (0x0738)

H264_DMA_INLINK_DSCR_BF1_CH2 Represents the address of the previous descriptor x-1 that is pre-read. (RO)


Register 39.256. H264_DMA_IN_FIFO_CNT_CH2_REG (0x0780)

H264_DMA_IN_CMDFIFO_INFIFO_CNT_CH2 Represents the remaining request data in FIFO. (RO)


Register 39.257. H264_DMA_IN_POP_DATA_CNT_CH2_REG (0x0784)

H264_DMA_IN_CMDFIFO_POP_DATA_CNT_CH2 Represents the data quantity in the current AXI request. (RO)
