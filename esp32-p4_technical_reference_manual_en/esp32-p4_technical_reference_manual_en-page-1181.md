

```markdown
Register 19.53. PMS_DMA_DMA2D_DUMMY_PMS_R_REG (0x020C)

PMS_DMA_DMA2D_DUMMY_R_PMS Configures 2D-DMA permission to read 32 address ranges requested by Dummy. Bit 0 corresponds to region0, and so on.

O: Disable read permission.
1: Enable read permission.
(R/W)
```

```markdown
Register 19.54. PMS_DMA_DMA2D_DUMMY_PMS_W_REG (0x0210)

PMS_DMA_DMA2D_DUMMY_W_PMS Configures 2D-DMA permission to write 32 address ranges requested by Dummy. Bit 0 corresponds to region0, and so on.

O: Disable write permission.
1: Enable write permission.
(R/W)
```
