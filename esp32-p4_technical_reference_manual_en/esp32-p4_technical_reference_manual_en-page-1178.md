

```markdown
Register 19.47. PMS_DMA_L2MEM_MON_PMS_W_REG (0x01E0)

PMS_DMA_L2MEM_MON_W_PMS Configures write permission for L2MEM monitor to access 32 address ranges. Bit 0 corresponds to region0, and so on.

O: Disable write permission.
1: Enable write permission.

(R/W)
```
