Register 19.27. PMS_DMA_AXI_PDMA_PARLIO_R_PMS_REG (0x018C)

PMS_DMA_AXI_PDMA_PARLIO_R_PMS Configures GDMA-AXI permission to read 32 address ranges requested by PARLIO (Parallel IO Controller). Bit 0 corresponds to region0, and so on.

O: Disable read permission.
1: Enable read permission.
(R/W)

Register 19.28. PMS_DMA_AXI_PDMA_PARLIO_W_PMS_REG (0x0190)

PMS_DMA_AXI_PDMA_PARLIO_W_PMS Configures GDMA-AXI permission to write 32 address ranges requested by PARLIO. Bit 0 corresponds to region0, and so on.

O: Disable write permission.
1: Enable write permission.
(R/W)
