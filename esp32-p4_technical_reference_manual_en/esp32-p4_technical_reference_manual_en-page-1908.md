```markdown
Register 39.64. H264_DMA_OUT_MODE_ENABLE_CHO_REG (0x0050)

H264_DMA_OUT_TEST_MODE_ENABLE_CHO   Configures whether to enable test mode of TX channel 0.
0: TX channel 0 work in normal mode
1: TX channel 0 work in test mode
(R/W)
```

```markdown
Register 39.65. H264_DMA_OUT_MODE_YUV_CHO_REG (0x0054)

H264_DMA_OUT_TEST_Y_VALUE_CHO   Configures y value in test mode. (R/W)

H264_DMA_OUT_TEST_U_VALUE_CHO   Configures u value in test mode. (R/W)

H264_DMA_OUT_TEST_V_VALUE_CHO   Configures v value in test mode. (R/W)
```
