```markdown
Register 51.27. USB_SERIAL_JTAG_BUS_RESET_ST_REG (0x0068)

USB_SERIAL_JTAG_USB_RESET_ST Represents whether USB bus reset is released.
0: USB Serial/JTAG is in USB bus reset status
1: USB bus reset is released
(RO)
```
