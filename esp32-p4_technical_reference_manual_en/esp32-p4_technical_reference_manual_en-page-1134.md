Register 18.10. RTC_TIMER_INT_RAW_REG (0x0028)

RTC_TIMER_OVERFLOW_RAW   The interrupt raw status for the 48-bit counter overflow. (RO)

RTC_TIMER_MAIN_TIMER_INT_RAW   The interrupt raw status for the RTC Timer reaching the target time 0. (RO)

RTC_TIMER_OVERFLOW_ST   The interrupt status for the 48-bit counter overflow. (RO)

RTC_TIMER_MAIN_TIMER_INT_ST   The interrupt status for the RTC Timer reaching the target time 0. (RO)
