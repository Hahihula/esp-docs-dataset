Register 37.27. PPA_BLEND_ST_REG (0x0074)

PPA_BLEND_SIZE_DIFF_ST   Represents whether the size of the BLEND background and foreground images are consistent.
    0: Consistent
    1: Different
    (RO)

PPA_BLEND_YUV_X_SCALE_ERR_ST   Represents the image width (X) is odd for YUV422 or YUV420 formats. (RO)

PPA_BLEND_YUV_Y_SCALE_ERR_ST   Represents the image height (Y) is odd for the YUV420 format. (RO)
