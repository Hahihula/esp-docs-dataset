Register 14.7. PMU_HP_ACTIVE_BACKUP_CLK_REG (0x0020)

PMU_HP_ACTIVE_BACKUP_ICG_FUNC_EN Configures whether to enable each peripheral's function clock when the target state is HP_ACTIVE. For details, please refer to Table 14.4-2.

O: Disable
1: Enable
