ESP32-P4's GDMA module can generate the following interrupt signals that will be sent to the **Interrupt Matrix**.

*   AHB/AXI_PDMA_IN_CHO_INTR
*   AHB/AXI_PDMA_IN_CH1_INTR
*   AHB/AXI_PDMA_IN_CH2_INTR
*   AHB/AXI_PDMA_OUT_CHO_INTR
*   AHB/AXI_PDMA_OUT_CH1_INTR
*   AHB/AXI_PDMA_OUT_CH2_INTR
