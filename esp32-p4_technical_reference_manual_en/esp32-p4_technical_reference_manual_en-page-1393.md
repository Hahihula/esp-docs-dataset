22.3.1 Message Registers

The LP Mailbox provides sixteen 32-bit message registers in total, denoted as MB_MESSAGE_0_REG ~ MB_MESSAGE_15_REG, for caching inter-core communication messages. Both LP CPU and HP CPU0/1 can read and write these message registers to pass or retrieve message.

Read and write message registers is done through the APB bus, using APB_CLK, which is the only one clock in LP Mailbox. For more information about the clock, please refer to Chapter 10 Reset and Clock.

22.3.2 Interrupts

*   MB_LP_INTR
*   MB_HP_INTR
