Register 10.61. LP_CLKRST_LP_RST_EN_REG (0x000C)

LP_CLKRST_RST_EN_LP_HUK Configures whether to reset LP HUK.
O: Release from reset
1: Reset

1: Reset

1: Reset
(R/W)

O: Release from reset
1: Reset
(R/W)

LP_CLKRST_RST_EN_LP_RTC Configures whether to reset the LP clock calibration module.
O: Release from reset
1: Reset
(R/W)

LP_CLKRST_RST_EN_LP_MAILBOX Configures whether to reset LP Mailbox.
O: Release from reset
1: Reset
(R/W)

LP_CLKRST_RST_EN_LP_AONEFUSEREG Configures whether to reset LP eFuse.
O: Release from reset
1: Reset
(R/W)

LP_CLKRST_RST_EN_LP_RAM Configures whether to reset LP RAM.
O: Release from reset
1: Reset
(R/W)
