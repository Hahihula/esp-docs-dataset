Register 39.284. H264_DMA_IN_FIFO_CNT_CH5_REG (0x0A80)

H264_DMA_IN_CMDFIFO_INFIFO_CNT_CH5 Represents the remaining request data in FIFO. (RO)


Register 39.285. H264_DMA_IN_POP_DATA_CNT_CH5_REG (0x0A84)

H264_DMA_IN_CMDFIFO_POP_DATA_CNT_CH5 Represents the data quantity in the current AXI request. (RO)


Register 39.286. H264_DMA_IN_XADDR_CH5_REG (0x0A88)

H264_DMA_IN_CMDFIFO_XADDR_CH5 Represents the address of the current AXI request. (RO)
