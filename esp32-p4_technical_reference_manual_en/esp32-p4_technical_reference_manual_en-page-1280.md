```markdown
Register 20.41. HP_SYSTEM_HP_L1_CACHE_PWR_CTRL_REG (0x0110)

HP_SYSTEM_L1_CACHE_MEM_FO Configures whether or not to force L1 cache on.
- 0: Disable
- 1: Enable
(R/W)
```

```markdown
Register 20.42. HP_SYSTEM_HP_L2_CACHE_PWR_CTRL_REG (0x0114)

HP_SYSTEM_L2_CACHE_MEM_FO Configures whether or not to force L2 cache on.
- 0: Disable
- 1: Enable
(R/W)
```
