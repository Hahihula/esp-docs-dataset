It must be noted that the external interrupts are assigned to CLIC interrupt IDs 16 and onwards. Thus, the MCLICBASE offset can also be written as `0x1000 + 4*i`, where “i” represents the CLIC ID, and n = i + 16. On the other hand, the descriptions of these registers use the CLIC index “i” to specify the offset instead of the external interrupt index “n”, which is used here just for a matter of convenience.\n```
