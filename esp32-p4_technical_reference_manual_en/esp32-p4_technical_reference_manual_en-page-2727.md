Register 53.29. TWAI_DATA_10_REG (0x0068)

TWAI_DATA_10 In Operation mode, configures the 10th byte information of the data to be transmitted, or reads the 10th byte information of the data received. (R/W)
In Reset mode, reserved. (RO)

In Reset mode, reserved. (RO)
