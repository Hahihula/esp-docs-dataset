Register 54.12. SDHOST_DEBNCE_REG (0x0064)

SDHOST_DEBOUNCE_COUNT Configures the number of host clocks (clk) used by debounce filter logic. The typical debounce time is 5 ~ 25 ms to prevent the card instability when the card is inserted or removed. (R/W)


Register 54.13. SDHOST_USRID_REG (0x0068)

SDHOST_USRID_REG Configures user identification, value set by users. Can also be used as a scratchpad register by users. (R/W)


Register 54.14. SDHOST_VERID_REG (0x006C)

SDHOST_VERSIONID_REG Represents hardware version. Can also be read by firmware. (RO)
