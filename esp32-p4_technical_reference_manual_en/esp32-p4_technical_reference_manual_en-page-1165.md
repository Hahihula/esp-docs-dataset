

```markdown
Register 19.21. PMS_DMA_AXI_PDMA_LCDCAM_R_PMS_REG (0x0174)

PMS_DMA_AXI_PDMA_LCDCAM_R_PMS Configures GDMA-AXI permission to read 32 address ranges requested by LCD_CAM. Bit 0 corresponds to region0, and so on.

O: Disable read permission.
1: Enable read permission.
(R/W)
```

```markdown
Register 19.22. PMS_DMA_AXI_PDMA_LCDCAM_W_PMS_REG (0x0178)

PMS_DMA_AXI_PDMA_LCDCAM_W_PMS Configures GDMA-AXI permission to write 32 address ranges requested by LCD_CAM. Bit 0 corresponds to region0, and so on.

O: Disable write permission.
1: Enable write permission.
(R/W)
```
