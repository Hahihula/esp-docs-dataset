Chapter 21 Debug Assistant

Register 21.47. ASSIST_DEBUG_CORE_O_DEBUG_MODE_REG (0x0074)

ASSIST_DEBUG_CORE_O_DEBUG_MODE Represents whether HP CPU0 is in debugging mode.
1: In debugging mode
0: Not in debugging mode
(RO)

ASSIST_DEBUG_CORE_O_DEBUG_MODULE_ACTIVE Represents the status of the HP CPU0 debug module.
1: Active status
Other: Inactive status
(RO)
