

```markdown
Register 19.31. PMS_DMA_AXI_PDMA_SHA_R_PMS_REG (0x019C)

PMS_DMA_AXI_PDMA_SHA_R_PMS   Configures GDMA-AXI permission to read 32 address ranges requested by SHA. Bit 0 corresponds to region0, and so on.
O: Disable read permission.
1: Enable read permission.
(R/W)
```

```markdown
Register 19.32. PMS_DMA_AXI_PDMA_SHA_W_PMS_REG (0x01A0)

PMS_DMA_AXI_PDMA_SHA_W_PMS   Configures GDMA-AXI permission to write 32 address ranges requested by SHA. Bit 0 corresponds to region0, and so on.
O: Disable write permission.
1: Enable write permission.
(R/W)
```
