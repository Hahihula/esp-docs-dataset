Register 12.139. COREO_INTR_SRC_PASS_IN_SEC_STATUS_1_REG (0x0234)

COREO_INTR_SRC_PASS_IN_SEC_STATUS_1 Represents whether interrupt sources 32 ~ 63 have enabled the interrupt delegation function. Each bit corresponds to the enable status of one interrupt source.
0: Corresponding interrupt source has not enabled the interrupt delegation function.
1: Corresponding interrupt source has enabled the interrupt delegation function.
(RO)

Register 12.140. COREO_INTR_SRC_PASS_IN_SEC_STATUS_2_REG (0x0238)

COREO_INTR_SRC_PASS_IN_SEC_STATUS_2 Represents whether interrupt source 64 ~ 95 has enabled the interrupt delegation function. Each bit corresponds to the enable status of one interrupt source.
0: Corresponding interrupt source has not enabled the interrupt delegation function.
1: Corresponding interrupt source has enabled the interrupt delegation function.
(RO)
