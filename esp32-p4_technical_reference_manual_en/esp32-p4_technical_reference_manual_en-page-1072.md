Chapter 15 System Timer

Register 15.3. SYSTIMER_UNITO_LOAD_HI_REG (0x000C)

SYSTIMER_TIMER_UNITO_LOAD_HI Configures the value to be loaded to UNITO, high 20 bits.
(R/W)

Register 15.4. SYSTIMER_UNITO_LOAD_LO_REG (0x0010)

SYSTIMER_TIMER_UNITO_LOAD_LO Configures the value to be loaded to UNITO, low 32 bits. (R/W)

Register 15.5. SYSTIMER_UNITO_VALUE_HI_REG (0x0040)

SYSTIMER_TIMER_UNITO_VALUE_HI Represents UNITO read value, high 20 bits. (RO)
