Chapter 39 H264 Encoder

Register 39.287. H264_DMA_IN_BUF_HB_RCV_CH5_REG (0x0A8C)

H264_DMA_IN_CMDFIFO_BUF_HB_RCV_CH5 Represents the data quantity that has been requested. (RO)

Register 39.288. H264_DMA_INTER_AXI_ERR_REG (0x0B00)

H264_DMA_INTER_RID_ERR_CNT Represents the count of errors in the internal memory ID for AXI read operations. (RO)

H264_DMA_INTER_RRESP_ERR_CNT Represents the count of errors in the response for internal memory during AXI read operations. (RO)

H264_DMA_INTER_WRESP_ERR_CNT Represents the count of AXI write internal memory resp err. (RO)

H264_DMA_INTER_RD_FIFO_CNT Represents the count of cmd FIFO remain cmd in AXI read internal memory module. (RO)

H264_DMA_INTER_RD_BAK_FIFO_CNT Represents the count of backup cmd FIFO remain cmd in AXI read internal memory module.(RO)

H264_DMA_INTER_WR_FIFO_CNT Represents the count of cmd FIFO remain cmd in AXI write internal memory module. (RO)

H264_DMA_INTER_WR_BAK_FIFO_CNT Represents the count of backup cmd FIFO remain cmd in AXI write internal memory module. (RO)
