```markdown
Register 17.30. ASSIST_DEBUG_CORE_O_LASTPC_BEFORE_EXCEPTION_REG (0x0094)

ASSIST_DEBUG_CORE_O_LASTPC_BEFORE_EXC Records the PC of the last command before the CPU enters exception. (RO)
```

```markdown
Register 17.31. ASSIST_DEBUG_CORE_O_DEBUG_MODE_REG (0x0098)

ASSIST_DEBUG_CORE_O_DEBUG_MODE Indicates whether the RISC-V CPU is in debug mode. 1: in debug mode; 0: not in debug mode. (RO)

ASSIST_DEBUG_CORE_O_DEBUG_MODULE_ACTIVE Indicates the status of the RISC-V CPU debug module. 1: active status; 0: inactive status. (RO)
```
