Register 10.14. SYSTIMER_TARGETO_HI_REG (0x001C)

SYSTIMER_TIMER_TARGETO_HI The alarm value to be loaded to COMPO, high 20 bits. (R/W)


Register 10.15. SYSTIMER_TARGETO_LO_REG (0x0020)

SYSTIMER_TIMER_TARGETO_LO The alarm value to be loaded to COMPO, low 32 bits. (R/W)


Register 10.16. SYSTIMER_TARGETO_CONF_REG (0x0034)

SYSTIMER_TARGETO_PERIOD COMPO alarm period. (R/W)
SYSTIMER_TARGETO_PERIOD_MODE Set COMPO to period mode. (R/W)
SYSTIMER_TARGETO_TIMER_UNIT_SEL Select which unit to compare for COMPO. (R/W)
