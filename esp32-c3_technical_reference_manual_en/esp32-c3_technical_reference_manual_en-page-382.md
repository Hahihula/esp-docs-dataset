Register 14.46. PMS_CORE_O_PIF_PMS_CONSTRAIN_9_REG (0x00FC)

PMS_CORE_O_PIF_PMS_CONSTRAIN_RTCFAST_SPLTADDR_M_MODE   Configures the address to split RTC Fast Memory into two regions in unprivileged environment for CPU. Note you should use address offset, instead of absolute address. (R/WL)

PMS_CORE_O_PIF_PMS_CONSTRAIN_RTCFAST_SPLTADDR_U_MODE   Configures the address to split RTC Fast Memory into two regions in privileged environment for CPU. Note you should use address offset, instead of absolute address. (R/WL)
