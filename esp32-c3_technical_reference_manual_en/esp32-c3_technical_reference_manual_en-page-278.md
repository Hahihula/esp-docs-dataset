Register 10.2. SYSTIMER_UNITO_OP_REG (0x0004)

SYSTIMER_TIMER_UNITO_UPDATE   Update timer UNITO, i.e. read the UNITO count value to SYS-TIMER_TIMER_UNITO_VALUE_HI and SYSTIMER_TIMER_UNITO_VALUE_LO. (WT)

Register 10.3. SYSTIMER_UNITO_LOAD_HI_REG (0x000C)

SYSTIMER_TIMER_UNITO_LOAD_HI   The value to be loaded to UNITO, high 20 bits. (R/W)

Register 10.4. SYSTIMER_UNITO_LOAD_LO_REG (0x0010)

SYSTIMER_TIMER_UNITO_LOAD_LO   The value to be loaded to UNITO, low 32 bits. (R/W)
