Register 14.36. PMS_CORE_O_DRAMO_PMS_MONITOR_1_REG (0x00CC)
```

| Bit Field | Description |
|-----------|-------------|
| 31-2       | reserved     |
| 1         | Reset        |

PMS_CORE_O_DRAMO_PMS_MONITOR_VIOLATE_CLR Set this bit to clear the interrupt triggered when CPUO's dBUS tries to access SRAM or ROM unauthorized. (R/WL)

PMS_CORE_O_DRAMO_PMS_MONITOR_VIOLATE_EN Set this bit to enable interrupt when CPUO's dBUS tries to access SRAM or ROM unauthorized. (R/WL)
```
