Register 4.23. EFUSE_RD_MAC_SPI_SYS_5_REG (0x0058)

Register 4.24. EFUSE_RD_SYS_PART1_DATA0_REG (0x005C)

Register 4.25. EFUSE_RD_SYS_PART1_DATA1_REG (0x0060)
