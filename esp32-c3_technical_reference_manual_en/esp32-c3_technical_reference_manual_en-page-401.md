Register 14.69. PMS_CORE_O_PIF_PMS_MONITOR_5_REG (0x0144)

PMS_CORE_O_PIF_PMS_MONITOR_NONWORD_VIOLATE_INTR Stores the interrupt status of PIF upsupported data type. (RO)
PMS_CORE_O_PIF_PMS_MONITOR_NONWORD_VIOLATE_STATUS_HSIZE Stores the data type when the unauthorized access happened. (RO)
PMS_CORE_O_PIF_PMS_MONITOR_NONWORD_VIOLATE_STATUS_HWORLD Stores the privileged mode the CPU was in when the unauthorized access happened. 01: privileged environment 10: unprivileged environment. (RO)
