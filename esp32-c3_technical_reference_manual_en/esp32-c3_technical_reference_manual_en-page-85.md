Register 2.20. GDMA_IN_DSCR_BFO_CHn_REG (n: 0-2) (0x0094+192*n)

GDMA_INLINK_DSCR_BFO_CHn Represents the address of the current receive descriptor x that is pre-read. (RO)

Register 2.21. GDMA_IN_DSCR_BF1_CHn_REG (n: 0-2) (0x0098+192*n)

GDMA_INLINK_DSCR_BF1_CHn Represents the address of the previous receive descriptor x-1 that is pre-read. (RO)
