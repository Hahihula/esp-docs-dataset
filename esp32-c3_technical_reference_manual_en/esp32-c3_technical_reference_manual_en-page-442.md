Register 16.15. SYSTEM_CPU_INTR_FROM_CPU_2_REG (0x0030)

SYSTEM_CPU_INTR_FROM_CPU_2   Set this bit to generate CPU interrupt 2. This bit needs to be reset by software in the ISR process. (R/W)
