Register 12.2. PMU_HP_ACTIVE_ICG_HP_FUNC_REG (0x0004)

PMU_HP_ACTIVE_DIG_ICG_FUNC_EN Configures whether to enable HP system peripheral's function clock in HP_ACTIVE state. For detailed configuration please see Table 12.4-2.

O: Disable
1: Enable

(R/W)
