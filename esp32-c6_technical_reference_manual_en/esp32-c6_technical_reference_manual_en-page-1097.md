Register 33.10. TWAI_DATA_5_REG (0x0054)

TWAI_TX_BYTE_5 Configures the 5th byte information of the data to be transmitted in Operation mode. (WO)
TWAI_ACCEPTANCE_MASK_1 Configures the 1st byte of the filter code in Reset mode. (R/W)


Register 33.11. TWAI_DATA_6_REG (0x0058)

TWAI_TX_BYTE_6 Configures the 6th byte information of the data to be transmitted in Operation mode. (WO)
TWAI_ACCEPTANCE_MASK_2 Configures the 2nd byte of the filter code in Reset mode. (R/W)
