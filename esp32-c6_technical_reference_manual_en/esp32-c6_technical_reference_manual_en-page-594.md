```markdown
## Register 16.57. LP_TEE_CLOCK_GATE_REG (0x0004)

LP_TEE_CLK_EN Configures whether to keep the clock always on.
- O: enable automatic clock gating
- 1: keep the clock always on
(R/W)
```

```markdown
## Register 16.58. LP_TEE_FORCE_ACC_HP_MEM_REG (0x0090)

LP_TEE_FORCE_ACC_HPMEM_EN Configures whether to allow LP CPU to force access to HP_MEM regardless of permission management.
- O: disable force access HP_MEM
- 1: enable force access HP_MEM
(R/W)
```
