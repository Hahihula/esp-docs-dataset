```markdown
Register 10.69. INTPRI_COREO_CPU_INT_CLEAR_REG (0x00A8)

INTPRI_COREO_CPU_INT_CLEAR Configures whether to clear the corresponding CPU interrupt.
0: No effect
1: Clear
For more information about how to use this register, see Chapter 1 High-Performance CPU.
(R/W)
```
