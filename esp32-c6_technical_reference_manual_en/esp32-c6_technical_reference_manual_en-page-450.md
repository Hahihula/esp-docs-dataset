Register 12.12. PMU_HP_MODEM_ICG_HP_FUNC_REG (0x0038)

PMU_HP_MODEM_DIG_ICG_FUNC_EN   Configures whether to enable HP system peripheral's function clock in HP_MODEM state. For detailed configuration please see Table 12.4-2.
O: Disable
1: Enable
(R/W)
