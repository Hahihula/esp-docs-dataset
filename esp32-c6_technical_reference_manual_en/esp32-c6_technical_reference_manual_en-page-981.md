

```markdown\nChapter 30 I2S Controller (I2S)\nGoBack\n\nThe following formula shows the relation between I2S_TX/RX_CLK frequency \(f_{\\text{I2S_TX/RX_CLK}}\) and the divider clock source frequency \(f_{\\text{I2S_CLK_S}}\):\n\n\\[\nf_{\\text{I2S_TX/RX_CLK}} = \\frac{f_{\\text{I2S_CLK_S}}}{N + \\frac{b}{a}}\n\\]\n\nN is an integer value between 2 and 256. The value of N corresponds to the value of `PCR_I2S_TX/RX_CLKM_DIV_NUM` in register `PCR_I2S_TX/RX_CLKM_CONF_REG` as follows:\n\n* When `PCR_I2S_TX/RX_CLKM_DIV_NUM = 0`, N = 256;\n* When `PCR_I2S_TX/RX_CLKM_DIV_NUM = 1`, N = 2;\n* When `PCR_I2S_TX/RX_CLKM_DIV_NUM` has any other value, N = `PCR_I2S_TX/RX_CLKM_DIV_NUM`.\n\nThe values of “a” and “b” in fractional divider depend only on x, y, z, yn1. The corresponding formulas are as follows:\n\n* When \(b \\leq \\frac{a}{2}\), yn1 = 0, \(x = \\text{floor}(\\left\\lfloor\\frac{a}{8}\\right\\rfloor - 1)\), y = a%b, z = b;\n* When \(b > \\frac{a}{2}\), yn1 = 1, \(x = \\text{floor}(\\left\\lfloor\\frac{a}{8}-b\\right\\rfloor) - 1\), y = a%(a - b), z = a - b.\n\nThe values of x, y, z, and yn1 are configured in `PCR_I2S_TX/RX_CLKM_DIV_X`, `PCR_I2S_TX/RX_CLKM_DIV_Y`, `PCR_I2S_TX/RX_CLKM_DIV_Z`, and `PCR_I2S_TX/RXCLKM_DIV_YN1`.\n\nTo configure the integer divider, clear `PCR_I2S_TX/RX_CLKM_DIV_X` and `PCR_I2S_TX/RX_CLKM_DIV_Z`, then set `PCR_I2S_TX/RX_CLKM_DIV_Y` to 1.\n\n**Note:**\nUsing fractional divider may introduce some clock jitter.\n\nIn master TX mode, the serial clock BCK for I2S_TX unit is I2SO_BCK_out divided from I2S_TX_CLK, which is:\n\n\\[\nf_{\\text{I2SO_BCK_out}} = \\frac{f_{\\text{I2S_TX_CLK}}}{\\text{MO}}\n\\]\n\n“MO” is an integer value:\n\n\\[\n\\text{MO} = \\text{I2S_TX_BCK_DIV_NUM} + 1\n\\]\n\n**Note:**\nNote that `I2S_TX_BCK_DIV_NUM` must not be configured as 1.\n\nIn master RX mode, the serial clock BCK for I2S_RX unit is I2SI_BCK_out divided from I2S_RX_CLK, which is:\n\n\\[\nf_{\\text{I2SI_BCK_out}} = \\frac{f_{\\text{I2S_RX_CLK}}}{\\text{MI}}\n\\]\n\n“MI” is an integer value:\n\n\\[\n\\text{MI} = \\text{I2S_RX_BCK_DIV_NUM} + 1\n\\]\n```
