Chapter 12 Low-Power Management

Register 12.17. PMU_HP_MODEM_BACKUP_CLK_REG (0x0054)

PMU_HP_MODEM_BACKUP_ICG_FUNC_EN Configures whether to enable each peripheral's function clock when the target state is HP_MODEM. For details, please refer to Chapter 8 Reset and Clock.

O: Disable
1: Enable
(R/W)
