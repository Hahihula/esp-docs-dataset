```markdown
Register 10.64. INTPRI_COREO_CPU_INT_ENABLE_REG (0x0000)

INTPRI_COREO_CPU_INT_ENABLE Configures whether to enable the corresponding CPU interrupt.
0: Not enable
1: Enable
For more information about how to use this register, see Chapter 1 High-Performance CPU.
(R/W)
```

```markdown
Register 10.65. INTPRI_COREO_CPU_INT_TYPE_REG (0x0004)

INTPRI_COREO_CPU_INT_TYPE Configures CPU interrupt type.
0: Level-triggered
1: Edge-triggered
For more information about how to use this register, see Chapter 1 High-Performance CPU.
(R/W)
```
