Register 35.20. LEDC_CHn_GAMMA_RD_ADDR_REG (n: 0-5) (0x0108+0x10*n)

LEDC_CHn_GAMMA_RD_ADDR Configures LEDC channel n gamma RAM read address. (R/W)


Register 35.21. LEDC_CHn_GAMMA_RD_DATA_REG (n: 0-5) (0x010C+0x10*n)

LEDC_CHn_GAMMA_RD_DATA Represents data read from gamma RAM via LEDC channel n. (RO)
