Register 18.4. MEM_MONITOR_LOG_MIN_REG (0x000C)

MEM_MONITOR_LOG_MIN Configures the lower bound address of the monitored address space.
(R/W)
```

Register 18.5. MEM_MONITOR_LOG_MAX_REG (0x0010)

(R/W)
```

Register 18.6. MEM_MONITOR_LOG_MEM_START_REG (0x0014)
