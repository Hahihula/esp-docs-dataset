Register 12.22. PMU_HP_SLEEP_ICG_HP_FUNC_REG (0x006C)

PMU_HP_SLEEP_DIG_ICG_FUNC_EN   Configures whether to enable HP system peripheral's function clock in HP_SLEEP state. For detailed configuration please see Table 12.4-2.
O: Disable
1: Enable
(R/W)
