Register 16.18. HP_APM_M3_STATUS_REG (0x00F8)

HP_APM_M3_EXCEPTION_STATUS Represents exception status.
bit0: 1 represents authority_exception
bit1: 1 represents space_exception
(RO)

Register 16.19. HP_APM_M3_STATUS_CLR_REG (0x00FC)

HP_APM_M3_REGION_STATUS_CLR Configures to clear exception status. (WT)

Register 16.20. HP_APM_M3_EXCEPTION_INFO0_REG (0x0100)

HP_APM_M3_EXCEPTION_REGION Represents exception region. (RO)
HP_APM_M3_EXCEPTION_MODE Represents exception mode. (RO)
HP_APM_M3_EXCEPTION_ID Represents exception id information. (RO)
