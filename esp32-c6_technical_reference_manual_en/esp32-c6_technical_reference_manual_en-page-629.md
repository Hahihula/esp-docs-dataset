Register 18.23. ASSIST_DEBUG_CORE_O_AREA_SP_REG (0x0034)

ASSIST_DEBUG_CORE_O_AREA_SP Represents the SP value when an interrupt is triggered during region monitoring. (RO)


Register 18.24. ASSIST_DEBUG_CORE_O_SP_MIN_REG (0x0038)

ASSIST_DEBUG_CORE_O_SP_MIN Configures the lower bound address of SP. (R/W)


Register 18.25. ASSIST_DEBUG_CORE_O_SP_MAX_REG (0x003C)

ASSIST_DEBUG_CORE_O_SP_MAX Configures the upper bound address of SP. (R/W)
