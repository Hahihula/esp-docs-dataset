Register 39.21. APB_TSENS_SAMPLE_REG (0x0068)

APB_SARADC_TSENS_SAMPLE_RATE Configures the hardware sampling rate. (R/W)
APB_SARADC_TSENS_SAMPLE_EN Configures whether to enable hardware sampling.
O: Disable
1: Enable
(R/W)

Register 39.22. APB_SARADC_CTRL_DATE_REG (0x03FC)

APB_SARADC_DATE Version control register. (R/W)
