DT_CLK can be selected from PWM_clk or PT_clk through register `MCPWM_DTx_CLK_SEL`.\n\nTo calculate the delay on falling edge (FED) and rising edge (RED), use the following formulas:\n\n```math\nFED = MCPWM_DTx_FED \times T_{DT\_clk}\nPWR = MCPWM_DTx_RED \times T_{DT\_clk}\n```\n\nEspressif Systems 1218 ESP32-C6 TRM (Version 1.1)\n```
