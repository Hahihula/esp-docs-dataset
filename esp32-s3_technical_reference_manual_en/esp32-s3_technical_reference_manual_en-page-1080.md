**Body Text with Annotations and Footnotes:**

All signals of LCD_CAM must be mapped to the chip’s pin via GPIO matrix. For more information, see Chapter 6 IO MUX and GPIO Matrix (GPIO, I/O MUX).

For the input/output signals with 8 or 16 bit width, N = 7 or 15 respectively.

If LCD_CAM_VH_DE_MODE_EN is set, i.e., VSYNC + HSYNC mode is selected, in this mode, the signals of VSYNC, HSYNC and DE are used to control the data. For this case, users need to wire the three signal lines. If LCD_CAM_VH_DE_MODE_EN is cleared, i.e., DE mode is selected, the signals of VSYNC and DE are used to control the data. For this case, wiring HSYNC signal line is not a must. But in this case, the YUV-RGB conversion function of camera module is not available.

**Subsection Title:**
29.3.3 LCD_CAM Module Clocks

**Sub-subsection Title and Subtitle with Link:**
29.3.3.1 LCD Clock
The clocks used in LCD module are generated by LCD_Clock Generator from clock sources, see Figure 29.3-2.

**Body Text under Sub-subsection:**

The clocks include:

- master clock: LCD_CLK, divided from clock sources

- pixel clock: LCD_PCLK, divided from LCD_CLK

The clock source can be one of the following, depending on the configuration of LCD_CAM_LCD_CLK_SEL in register LCD_CAM_LCD_CLK_REG:
- 0: disable LCD clock source
- 1: XTAL_CLK
- 2: PLL_D2_CLK
- 3: PLL_F160M_CLK
