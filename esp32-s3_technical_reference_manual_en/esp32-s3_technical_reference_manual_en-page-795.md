**Title: Chapter 15 Permission Control (PIC)**

### Register Information:

- **Register 15.99**: PMS_CORE_0_PIF_PMS_MONITOR_6_REG (0x01B4)
  - Description:
    ```
    PMS_CORE_0_PIF_PMS_MONITOR_NONWORD_VIOLATE_STATUS_HADDR
    Stores the address that CPU’s PIF bus was trying to access using unsupported data type. (RO)
    ```

- **Register 15.100**: PMS_DATE_REG (0x0FFC) - Sensitive Date register.
  - Description:
    ```
    PMS_DATE
    Sensitive Date register. (R/W)
    ```
