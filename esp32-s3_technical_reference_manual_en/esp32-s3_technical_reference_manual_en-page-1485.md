**Register Information:**
- **Register Name:** Register 39.7. RTC_CNTL_TOUCH_TIMEOUT_CTRL_REG (0x0124)
- **Field Description:**
  - **Field Name:** RTC_CNTL TOUCH TIMEOUT NUM
    - **Bits:** 23 to 0, with a reset value of `0x3ffffff`
    - **Description:** Set touch timeout threshold. (R/W)

  - **Field Name:** RTC_CNTL TOUCH TIMEOUT EN
    - **Bits:** Bit at position 1.
    - **Description:** Enable touch timeout. (R/W)
