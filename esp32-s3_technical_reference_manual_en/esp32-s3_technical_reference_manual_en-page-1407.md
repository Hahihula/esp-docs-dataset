- **MCPWM_FAULT1_CLR_INT_ENA**: The enable bit for the interrupt triggered when event_f1 ends.
  - Access Type: Read/Write

- **MCPWM_FAULT2_CLR_INT_ENA**: The enable bit for the interrupt triggered when event_f2 ends.
  - Access Type: Read/Write

- **MCPWM_OPO_TEA_INT_ENA**: The enable bit for the interrupt triggered by a PWM operator 0 TEA
  - Access Type: Read/Write

- **MCPWM_OP1_TEA_INT_ENA**: The enable bit for the interrupt triggered by a PWM operator 1 TEA
  - Access Type: Read/Write

- **MCPWM_OP2_TEA_INT_ENA**: The enable bit for the interrupt triggered by a PWM operator 2 TEA
  - Access Type: Read/Write

- **MCPWM_OPO_TEB_INT_ENA**: The enable bit for the interrupt triggered by a PWM operator 0 TEB
  - Access Type: Read/Write

- **MCPWM_OP1_TEB_INT_ENA**: The enable bit for the interrupt triggered by a PWM operator 1 TEB
  - Access Type: Read/Write

- **MCPWM_OP2_TEB_INT_ENA**: The enable bit for the interrupt triggered by a PWM operator 2 TEB
  - Access Type: Read/Write

- **MCPWM_FHO_CBC_INT_ENA**: The enable bit for the interrupt triggered by a cycle-by-cycle mode action on PWMO.
  - Access Type: Read/Write

- **MCPWM_FH1_CBC_INT_ENA**: The enable bit for the interrupt triggered by a cycle-by-cycle mode action on PWM1.
  - Access Type: Read/Write

- **MCPWM_FH2_CBC_INT_ENA**: The enable bit for the interrupt triggered by a cycle-by-cycle mode action on PWM2.
  - Access Type: Read/Write

- **MCPWM_FHO_OST_INT_ENA**: The enable bit for the interrupt triggered by a one-shot mode action on PWMO.
  - Access Type: Read/Write

- **MCPWM_FH1_OST_INT_ENA**: The enable bit for the interrupt triggered by a one-shot mode action on PWM1.
  - Access Type: Read/Write

- **MCPWM_FH2_OST_INT_ENA**: The enable bit for the interrupt triggered by a one-shot mode action on PWM2.
  - Access Type: Read/Write

- **MCPWM_CAPO_INT_ENA**: The enable bit for the interrupt triggered by capture on channel 0.

  - Access Type: Read/Write

- **MCPWM_CAP2_INT_ENA**: The enable bit for the interrupt triggered by capture on channel 2.
  - Access Type: Read/Write
