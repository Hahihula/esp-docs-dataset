**Register 5.60. EFUSE_RD_KEY2_DATA4_REG (0x0EC)**

- **EFUSE_KEY2_DATA4**
  - Represents the fifth 32 bits of KEY2.
  - Access mode: Read-only.

**Register 5.61. EFUSE_RD_KEY2_DATA5_REG (0x0F0)**
- **EFUSE_KEY2_DATA5**
  - Represents the sixth 32 bits of KEY2.

**Register 5.62. EFUSE_RD_KEY2_DATA6_REG (0x0F4)**
- **EFUSE_KEY2_DATA6**
  - Represents the seventh 32 bits of KEY2.

**Register 5.63. EFUSE_RD_KEY2_DATA7_REG (0x0F8)**
- **EFUSE_KEY2_DATA7**
  - Represents the eighth 32 bits of KEY2.
  - Access mode: Read-only.
