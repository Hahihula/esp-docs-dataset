**Title:**
Chapter 15 Permission Control (PMS)

**Register Information:**
- **Register Name:** PMS_DMA_APBPERI_I2S1_PMS CONSTRAINT O_REG (0x0058)
  
**Bit Description:**
- **Name:** PMS_DMA_APBPERI_I2S1_PMS CONSTRAINT LOCK
- **Function:** Set this bit to lock I2S1's GDMA permission configuration register. (R/W)
