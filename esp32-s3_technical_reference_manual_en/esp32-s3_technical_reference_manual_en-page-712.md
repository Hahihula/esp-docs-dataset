### Register Information

- **Register Name:** PMS_APB_PERIPHERAL_ACCESS_1_REG (0x000C)
- **Description:** Permission Control (PMS)

#### Bit Description:
- `PMS_APB_PERIPHERAL_ACCESS_SPLIT_BURST`
  - **Bit Range:** [31:0]
  - **Function:** Set this bit to allow the PIF bus to initiate back-to-back access to peripheral regions. (R/W)
  
- **Register Name:** PMS_INTERNAL_SRAM USAGE_0_REG (0x0010)
- **Description:** Permission Control (PMS)

#### Bit Description:
- `PMS_INTERNAL_SRAM USAGE LOOK`
  - **Bit Range:** [31:0]
  - **Function:** Set this bit to lock internal SRAM Configuration Register. (R/W)
