**Section Header: Register Description**

- **Register Name and Address:**
  - Register 3.20, GDMA_EXTMEM_REJECT_INT_ST_REG (0x0400)
  
- **Bit Description for Register 3.20:**
  - Bit name: GDMA_EXTMEM_REJECT_INT_ST
  - Description: The raw interrupt status bit for the GDMA_EXTMEM_REJECT_INT interrupt.
  - Access type: Read Only (RO)
