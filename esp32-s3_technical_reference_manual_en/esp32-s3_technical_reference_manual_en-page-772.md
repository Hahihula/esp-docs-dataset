**Title:**
Register 15.62, PMS_CORE_0_PIF_PMS_MONITOR_1_REG (0x0IAO)

**Body Text:**

- **PMS_CORE_0_PIF_PMS_MONITOR_VIOLATE_CLR**: Set this bit to clear the interrupt triggered when CPUO’s PIF bus tries to access RTC memory or peripherals unauthorized. (R/W)
  
- **PMS_CORE_0_PIF_PMS_MONITOR_VIOLATE_EN**: Set this bit to enable interrupt when CPUO’s PIF bus tries to access RTC memory or peripherals unauthorized. (R/W)
