**Section Header:**
Register 6.32. GPIO_STATUS_NEXT_REG (0x14C)

**Table Description for Register 6.32:**
- **Field Name:** GPIO_STATUS_INTERRUPT_NXT
- **Description:** Interrupt source signal of GPIO0 ~ 31, could be rising edge interrupt, falling edge interrupt, level sensitive interrupt and any edge interrupt.
- **Access Type:** (RO)
- **Bit Positions:** Not specified in the visible part.

**Section Header:**
Register 6.33. GPIO_STATUS_NEXT1_REG (0x150)

**Table Description for Register 6.33:**
- **Field Name:** GPIO_STATUS1_INTERRUPT_NXT
- **Description:** Interrupt source signal of GPIO32 ~ 48.
- **Access Type:** (RO)
- **Bit Positions:** Not specified in the visible part.

**Section Header:**
Register 6.34. GPIO_DATE_REG (0x06FC)

**Table Description for Register 6.34:**
- **Field Name:** GPIO_DATE
- **Description:** Version control register.
- **Access Type:** (R/W)
- **Bit Positions:** Not specified in the visible part.
