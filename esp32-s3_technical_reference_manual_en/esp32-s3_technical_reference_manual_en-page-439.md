**Section Header and Description for Register 5.26:**

- **Register Name:** EFUSE_RD_SYS_PART1_DATA2_REG (0x0064)
  
  - **Field Information:**
    - **EFUSE_OPTIONAL_UNIQUE_ID_2**: Represents the bits 64~95 of the optional unique id information.
      - **Access Type:** Read-Only
      - **Value Example:** 31, 0x000000 (with a reset option indicated)

  - **Field Information:**
