**Section Title:**
Register 10.58. RTC_CNTL_RTC_OPTION1_REG (0x012C)

**Body Text with Diagrams and Descriptions:**

- **Diagram Description:** 
  - Labelled as "RTC_CNTL_FORCE_DOWNLOAD_BOOT" showing a bit map.
  - Bits are numbered from right to left, starting at '31' on the far left. The description indicates that setting this specific bit will force chip enters download boot by software (sw.) and is read/write accessible.

- **Diagram Description:**
  - Labelled as "RTC_CNTL_SLP_WAKEUP_CAUSE_REG" showing a bit map.
  - Bits are numbered from right to left, starting at '16' on the far left. The description indicates that this register stores the wakeup cause (read-only).
