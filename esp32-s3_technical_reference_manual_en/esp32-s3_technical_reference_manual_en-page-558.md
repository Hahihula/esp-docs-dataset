**Section Title and Description:**

1. **Register 9.86. INTERRUPT_COREO_INTR_STATUS_1_REG (0x0190)**
   - **Interrupt Register:** INTERRUPT COREO INTR STATUS
   - **Status of the second 32 interrupt sources**: This register stores the status of the second 32 interrupt sources.
   - **Register Address and Type:**
     - **Address:** 0x0190
     - **Type:** (RO)

2. **Register 9.87. INTERRUPT_COREO_INTR_STATUS_2_REG (0x0194)**
   - **Interrupt Register:** INTERRUPT COREO INTR STATUS
   - **Status of the third 32 interrupt sources**: This register stores the status of the third 32 interrupt sources.
   - **Register Address and Type:**
     - **Address:** 0x0194

3. **Register 9.88. INTERRUPT_COREO_INTR_STATUS_3_REG (0x0198)**
   - **Interrupt Register:** INTERRUPT COREO INTR STATUS
   - **Status of the last 3 interrupt sources**: This register stores the status of the last 3 interrupt sources.
   - **Register Address and Type:**
     - **Address:** 0x0198
