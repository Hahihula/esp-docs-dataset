**Title:**
Register 15.6, PMS_DMA_APBPERI_SPI2_PMS CONSTRAINT O_REG (0x0038)

**Body Text:**
PMS_DMA_APBPERI_SPI2_PMS CONSTRAINT LOCK

Set this bit to lock SPI2’s GDMA permission configuration register.
