**Section Title: Register 5.114. EFUSE_INT_CLR_REG (0x01E4)**

- **Field Description:** 
  - `EFUSE_READ_DONE_INT_CLR`: Write 1 to clear READ_DONE.
    - Access Type: Write Only
  - `EFUSE_PGMDone_INT_CLR`: Write 1 to clear PGM_DONE.
    - Access Type: Write Only

---

**Section Title: Register 5.115. EFUSE_DATE_REG (0x01FC)**

- **Field Description:** 
  - `EFUSE_DATE`: Version control register
    - Access Type: Read/Write
