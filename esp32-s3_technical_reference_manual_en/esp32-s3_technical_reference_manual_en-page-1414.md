**Register Information:**

- **Register Name:** MCPWM_CLK_REG (0x0120)
  - **Description:** Force clock on for this register file. (R/W)
  - **Bit Pattern Diagram:**
    ```
    [31] (reserved) 
    [0] Reset
    ```

- **Register Name:** MCPWM_VERSION_REG (0x0124)
  - **Description:** Version of this register file. (R/W)
  - **Bit Pattern Diagram:**
    ```
    [31] 28 27 (reserved) 
    [0] Reset
    ```
