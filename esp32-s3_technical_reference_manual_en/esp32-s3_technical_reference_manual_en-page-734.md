**Title:**
Register 15.25. PMS_DMA_APBPERI_LCD_CAM_PMS CONSTRAINT_1_RSEG (0x0094)

**Body Text:**

- **PMS_DMA_APBPERI_LCD_CAM_PMS CONSTRAINT_SRAM_PMS_0**: Configure LCD_CAM’s permission to the instruction region. (R/W)
  
- **PMS_DMA_APBPERI_LCD_CAM_PMS CONSTRAINT_SRAM_PMS_1**: Configure LCD_CAM’s permission to data region 0 of SRAM. (R/W)

- **PMS_DMA_APBPERI_LCD_CAM_PMS CONSTRAINT_SRAM_PMS_2**: Configure LCD_CAM’s permission to data region 1 of SRAM. (R/W)

- **PMS_DMA_APBPERI_LCD_CAM_PMS CONSTRAINT_SRAM_PMS_3**: Configure LCD_CAM’s permission to data region 2 of SRAM. (R/W)

- **PMS_DMA_APBPERI_LCD_CAM_PMS CONSTRAINT_SRAM_CACHEDATAARRAY_PMS_0**: Configure LCD_CAM’s permission to SRAM block9. (R/W)

- **PMS_DMA_APBPERI_LCD_CAM_PMS CONSTRAINT_SRAM_CACHEDATAARRAY_PMS_1**: Configure LCD_CAM’s permission to SRAM block 10. (R/W)
