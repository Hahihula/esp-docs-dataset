**Title:**
Chapter 10 Low-power Management (RTC_CNTL)

**Subtitles and Body Texts with Descriptions of Registers:**

- **Register 10.49, RTC_CNTL_RTC_EXT_WAKEUP1_REG (0x00E0)**
  - Description:
    - `RTC_CNTL_EXT_WAKEUP1_SEL`: Selects a RTC GPIO to be the EXT1 wakeup source.
      - Access Type: Read/Write
    - `RTC_CNTL_EXT_WAKEUP1_STATUS_CLR`: Clears the EXT1 wakeup status.

- **Register 10.50, RTC_CNTL_RTC_EXT_WAKEUP1_STATUS_REG (0x00E4)**
  - Description:
    - `RTC_CNTL_EXT_WAKEUP1_STATUS`: Indicates the EXT1 wakeup status.
      - Access Type: Read Only
