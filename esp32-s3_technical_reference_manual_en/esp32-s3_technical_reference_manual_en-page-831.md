**Title:**
Chapter 17 System Registers (SYSTEM)

**Subtitle:**
Register 17.4. SYSTEM_PERIP_CLK_EN_NO_REG (0x0018)

**Table Description:**
The table lists various system registers related to clock enablement for different components in a microcontroller or similar device.

- **Columns:** 
  - The first column contains the register names.
  - Each row corresponds to one specific register, with its name and description below it. 

**Text Content (List of Registers):**
1. SYSTEM_SPI01_CLK_EN: Set this bit to enable SPI01 clock. (R/W)
2. SYSTEM_UART_CLK_EN: Set this bit to enable UART clock. (R/W)
3. SYSTEM_I2S0_CLK_EN: Set this bit to enable I2S0 clock. (R/W)
4. SYSTEM_UART1_CLK_EN: Set this bit to enable UART1 clock. (R/W)
5. SYSTEM_SPI2_CLK_EN: Set this bit to enable SPI2 clock. (R/W)
6. SYSTEM_I2C_EXTO_CLK_EN: Set this bit to enable I2C_EXTO clock. (R/W)
7. SYSTEM_UHClO_CLK_EN: Set this bit to enable UHCl0 clock. (R/W)
8. SYSTEM_RMT_CLK_EN: Set this bit to enable RMT clock. (R/W)
9. SYSTEM_PCNT_CLK_EN: Set this bit to enable PCNT clock. (R/W)
10. SYSTEM_LEDC_CLK_EN: Set this bit to enable LEDC clock. (R/W)
11. SYSTEM_TIMERGROUP_CLK_EN: Set this bit to enable TIMERGROUPO clock. (R/W)
12. SYSTEM_TIMERGROUP1_CLK_EN: Set this bit to enable TIMERGROUP1 clock. (R/W)
13. SYSTEM_SPI3_CLK_EN: Set this bit to enable SPI3 clock. (R/W)
14. SYSTEM_PWM0_CLK_EN: Set this bit to enable PWM0 clock. (R/W)
15. SYSTEM_EXTI1_CLK_EN: Set this bit to enable I2C_EXTI1 clock. (R/W)
16. SYSTEM_CAN_CLK_EN: Set this bit to enable CAN clock. (R/W)
17. SYSTEM_PWM1_CLK_EN: Set this bit to enable PWM1 clock. (R/W)
18. SYSTEM_I2S1_CLK_EN: Set this bit to enable I2S1 clock. (R/W)
19. SYSTEM_USB_CLK_EN: Set this bit to enable USB clock. (R/W)
20. SYSTEM_UART_MEM_CLK_EN: Set this bit to enable UART_MEM clock.

22. SYSTEM_SYSTIMER_CLK_EN: Set this bit to enable SYSTEM TIMER clock. (R/W)
23. SYSTEM_ADC2_ARB_CLK_EN: Set this bit to enable ADC2_ARB clock.
