**Subtitle:**
Register 36.34. MCPWM_GEN1FORCE_REG (0x084)

**Binary Diagram Description:**
- The diagram shows a binary representation of the register with bits labeled from bit 31 to bit 0.
- Each bit is associated with specific functions related to the PWM generator.

**Bit Labels and Functions:**

- **MCPWM_GEN1_CNTUFORCE_UPMETHOD:** Updating method for continuous software force of PWM generator. Descriptions include:
  - When all bits are set to 0, it means immediately; when bit0 is set to TEZ (TEA); when bit1 is set to TEP; when bit2 is set to TEA; when bit3 is set to TEB; when bit4 is set to sync; and finally, if bit5 is set to disable update. The description also mentions that "TEA/B here" means an event generated by the timer's value equaling that of register A/B.

- **MCPWM_GEN1_A_CNTUFORCE_MODE:** Continuous software force mode for PWM1A with options:
  - Low, high; disabled (R/W)

- **MCPWM_GEN1_B_CNTUFORCE_MODE:** Continuous software force mode for PWM1B similar to the above but specific modes are not detailed.

- **MCPWM_GEN1_A_NCIFORCE:** Trigger of non-continuous immediate software-force event for PWM1A with toggle trigger options:
  - Low, high; disabled (R/W)

- **MCPWM_GEN1_B_NCIFORCE:** Trigger similar to the above but specific modes are not detailed.
