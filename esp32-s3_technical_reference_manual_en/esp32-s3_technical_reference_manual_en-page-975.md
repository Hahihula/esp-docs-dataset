**Register Information with Descriptions:**

1. **Register 26.51, UHCI_REG_Q5_WORD1_REG (0x0064)**
   - Description:
     ```
     UHCI_SEND_Q5_WORD1

     UHCI_ALWAYS_SEND_NUM or UHCI_SINGLE_SEND_NUM.
     (R/W)
     ```
