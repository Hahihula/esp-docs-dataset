**Section Header:**
Register 10.47 RTC_CNTL_RTC_PAD_HOLD_REG (0x00D8)

**Body Text and Descriptions:**

Continued from the previous page...

- **RTC_CNTL_TOUCH_PAD13_HOLD**: Sets the touch GPIO 13 to hold.
- **RTC_CNTL TOUCH_PAD14_HOLD**: Sets the touch GPIO 14 to hold.

- **RTC_CNTL_X32P_HOLD**: Sets the x32p to hold. (R/W)
- **RTC_CNTL_X32N_HOLD**: Sets the x32n to hold. (R/W)

- **RTC_CNTL_PADAC1_HOLD**: Sets the padac1 to hold.
- **RTC_CNTL_PADAC2_HOLD**: Sets the padac2 to hold.

- **RTC_CNTL_RTC_PAD19_HOLD**: Sets the RTG GPIO 19 to hold.
- **RTC_CNTL_RTC_PAD20_HOLD**: Sets the RTG GPIO 20 to hold.

- **RTC_CNTL_RTC_PAD21_HOLD**: Sets the RTG GPIO 21 to hold.

**Section Header:**
Register 10.48 RTC_CNTL_DIG_PAD_HOLD_REG (0x00DC)

**Body Text and Descriptions:**

- **RTC_CNTL_DIG_PAD_HOLD**: Set GPIO 21 to GPIO 45 to hold.
  - Note: See bitmap to locate any GPIO.
