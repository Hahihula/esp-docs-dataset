**Title:**
Chapter 28 I2S Controller (I2S)

**Subtitle:**
Register 28.15. I2S_TX_TDM_CTRL_REG (0x0054)

**Table Description:**
- The table shows the bits of register `I2S_TX_TDM_CTRL_REG` with labels for each bit position.
- Bits are labeled as follows:
  - 31
  - ... (bits from 28 to 0)
  - Reset

**Body Text and Descriptions:**

1. **I2S_TX_TDM_CHAN0_EN**
   - Description: Enable the valid data output of I2S TX TDM channel 0.
   - Channel TX data is controlled by `I2S_TX_CHAN_EQUAL` and `I2S_SINGLE_DATA`.
   - Reference to Section [28.9.2.1](#).
   - Access type (R/W)
