**Register Section**
- **Register Name:** EFUSE_PGM_CHECK_VALUE2_REG (0x0028)
- **Field Description:** 
  - **Name:** EFUSE_PGM_RS_DATA_2
  - **Value:** 31 | 0x000000 [Reset]
  - **Description:** Configures the content of the 2nd 32-bit RS code to be programmed. (R/W)

- **Register Name:** EFUSE_RD_WR_DIS_REG (0x002C)
- **Field Description:**
  - **Name:** EFUSE_WR_DIS
  - **Value:** 31 | 0x000000 [Reset]
  - **Description:** Represents whether programming of corresponding eFuse part is disabled or enabled. 1: Disabled. 0: Enabled. (RO)
