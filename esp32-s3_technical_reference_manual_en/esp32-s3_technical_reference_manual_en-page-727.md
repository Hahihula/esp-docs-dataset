**Title:**
Chapter 15 Permission Control (PMS)

**Register Information:**
- **Register Name:** PMS_DMA_APBPER_SHA_PMS CONSTRAINT O_REG (0x0078)
- **Bit Description:** 
  - Bit Position: [31, 0]
  - Bit Name: PMS_DMA_APBPER_SHA_PMS CONSTRAINT LOCK
  - Function: Set this bit to lock SHA's GDMA permission configuration register. (R/W)
