**Section Title:** Register 5.80. EFUSE_RD_KEY5_DATAO_REG (0x013C)

- **Field Name:** EFUSE_KEY5_DATAO
- **Description:** Represents the first 32 bits of KEY5.
- **Access Type:** Read-only

---

**Section Title:** Register 5.81. EFUSE_RD_KEY5_DATA1_REG (0x0140)

- **Field Name:** EFUSE_KEY5_DATA1
- **Description:** Represents the second 32 bits of KEY5.

---

**Section Title:** Register 5.82. EFUSE_RD_KEY5_DATA2_REG (0x0144)

- **Field Name:** EFUSE_KEY5_DATA2
- **Description:** Represents the third 32 bits of KEY5.
- **Access Type:** Read-only

---

**Section Title:** Register 5.83. EFUSE_RD_KEY5_DATA3_REG (0x0148)

- **Field Name:** EFUSE_KEY5_DATA3
- **Description:** Represents the fourth 32 bits of KEY5.
