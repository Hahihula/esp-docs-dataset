**Section Header - Register Information**

- **Register Name and Address:**
  - **Register 2.14. RTC_I2C_SCL_LOW_REG (0x0000)**
    - **Binary Representation Diagram**: Shows the binary bits from bit 31 to bit 0, with some reserved bits marked.
    - **Description:** This register is used to configure how many clock cycles SCL remains low.

- **Register Name and Address:**
  - **Register 2.15. RTC_I2C_SCL_HIGH_REG (0x0014)**
    - **Binary Representation Diagram**: Similar binary bits representation as above.
    - **Description:** This register is used to configure how many cycles SCL remains high.

- **Register Name and Address:**
  - **Register 2.16. RTC_I2C_SDA_DUTY_REG (0x0018)**
    - **Binary Representation Diagram**: Similar binary bits representation as above.
    - **Description:** The number of clock cycles between the SDA switch and the falling edge of SCL.
