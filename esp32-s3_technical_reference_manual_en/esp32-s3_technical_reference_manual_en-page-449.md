**Register 5.64. EFUSE_RD_KEY3_DATA0_REG (0x0F0C)**

- **EFUSE_KEY3_DATA0**
  - Represents the first 32 bits of KEY3.
  - Access mode: Read-only
  - Address range: `0x000000`
  - Reset value: `0`
