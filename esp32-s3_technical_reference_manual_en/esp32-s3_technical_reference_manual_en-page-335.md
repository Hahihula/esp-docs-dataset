**Subtitle:**
Register 2.3. RTC_CNTL_ULP_CP_CTRL_REG (0x100)

**Body Text and Table Description:**

- **Table with binary values:** 
  - The table shows a series of bits labeled from "RTC_CNTL_ULPcp_START_TOP" to "RTC_CNTL_ULPcp_CLK_FO".
  
- **Descriptions for each bit in the register:**
  - RTC_CNTL_ULP_CP_CLK_FO (ULP-FSM clock force on. (R/W))
  - RTC_CNTL_ULP_CP_RESET (ULP-FSM clock software reset. (R/W))
  - RTC_CNTL_ULP_CP FORCE_START_TOP Write 1 to start ULP-FSM by software. (R/W)
  - RTC_CNTL_ULP_CP START_TOP Write 1 to start ULP-FSM. (R/W)
