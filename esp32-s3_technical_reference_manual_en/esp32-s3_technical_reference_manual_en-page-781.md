- **Name:** PMS_EDMA_PMS_UHClO_REG (0x2CC)
- **Description:** 
  - `PMS_EDMA_PMS_UHClO ATTR2`

- **Name:** PMS_EDMA_PMS_I2SO_LOCK_REG (0x2D0)
- **Description:**
  - `PMS_EDMA_PMS_I2SO_LOCK`
    Set this bit to lock the register that configures I2S0's access to external SRAM.
    For details, see Table 15.5-4.
