**Section Title: Register 10.52. RTC_CNTL_RTC_TIME_LOW1_REG (0x00EC)**

- **Field Description and Value:**
  - **Field Name:** RTC_CNTL_RTC_TIMER_VALUE1_LOW
  - **Value:** 31, 0x000000
  - **Description:** Stores the lower 32 bits of RTC timer 1. (RO)

**Section Title: Register 10.53. RTC_CNTL_RTC_TIME_HIGH1_REG (0x00F0)**

- **Field Description and Value:**
  - **Field Name:** RTC_CNTL_RTC_TIMER_VALUE1_HIGH
  - **Value:** reserved, 0x00
  - **Description:** Stores the higher 16 bits of RTC timer 1. (RO)

**Diagram/Block Diagrams:**
- [RTC_CNTL_RTC_TIMER_VALUE1_HIGH](#) with fields labeled as follows:

**Section Title: Register 10.54. RTC_CNTL_RTC_XTAL32K_CLK_FACTOR_REG (0x00F4)**

- **Field Description and Value:**
  - **Field Name:** RTC_CNTL_XTAL32K_CLK_FACTOR
  - **Value:** reserved, 0x000000
  - **Description:** Configures the divider factor for the 32 kHz crystal oscillator. (R/W)
