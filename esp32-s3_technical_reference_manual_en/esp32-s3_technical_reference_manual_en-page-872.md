**Section Title and Description:**

- **Register 19.12. AES_INT_CLR_REG (0x00AC)**
  - **Field:** AES_INT_CLR
    - **Description:** Set this bit to clear AES interrupt.
    - **Access Mode:** WO
  
- **Register 19.13. AES_INT_ENA_REG (0x00B0)**
  - **Field:** AES_INT_ENA
    - **Description:** Set this bit to enable AES interrupt and 0 to disable interrupt.
    - **Access Mode:** R/W
