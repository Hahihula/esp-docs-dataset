Chapter 26 UART Controller (UART)

**Section and Register Information with Descriptions:**

1. **Register Description:**  
   - **Register Number:** UHCI_REG_Q1_WORDO_REG (0x040)  
   - **Description:** This register is used as a quick_sent register when mode is specified by UHCI_ALWAYS_SEND_NUM or UHCI_SINGLE_SEND_NUM.
   
2. **Register Description:**
   - **Register Number:** UHCI Regel_Q1_WORD1_REG (0x044)
   - **Description:** This register is used as a quick_sent register when mode is specified by UHCI_ALWAYS_SEND_NUM or UHCI_SINGLE_SEND_NUM.

3. **Register Description:**
   - **Register Number:** UHCI Regel_Q2_WORDO_REG (0x048)
   - **Description:** This register is used as a quick_sent register when mode is specified by UHCI_ALWAYS_SEND_NUM or UHCI_SINGLE_SEND_NUM.
