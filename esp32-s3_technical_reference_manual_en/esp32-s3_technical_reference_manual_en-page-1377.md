**Table Title:**
Register 36.21. MCPWM_GENO_A_REG (0x005Q)

**Table Content Description:**
The table lists various registers related to the MCPWM_GENO_A寄存器, each with a specific bit range and description.

- **MCPWM_GENO_A_UTEZ**: Action on PWMOA triggered by event TEZ when timer increasing. 0: no change, 1: low, 2: high, 3: toggle.
- **MCPWM_GENO_A_UTEP**: Action on PWMOA triggered by event TEP when timer increasing. 0: no change, 1: low, 2: high, 3: toggle.
- **MCPWM_GENO_A_UTEA**: Action on PWMOA triggered by event TEA when timer increasing. 0: no change, 1: low, 2: high, 3: toggle.
- **MCPWM_GENO_A_UTEB**: Action on PWMOA triggered by event TEB when timer increasing. 0: no change, 1: low, 2: high, 3: toggle.
- **MCPWM_GENO_AUTO**: Action on PWMOA triggered by event_t0 when timer increasing. 0: no change, 1: low, 2: high, 3: toggle.
- **MCPWM_GENO_A_UT1**: Action on PWMOA triggered by event_t1 when timer increasing. 0: no change, 1: low, 2: high, 3: toggle.
- **MCPWM_GENO_A_DTEZ**: Action on PWMOA triggered by event TEZ when timer decreasing. 0: no change, 1: low, 2: high, 3: toggle.
- **MCPWM_GENO_A_DTEP**: Action on PWMOA triggered by event TEP when timer decreasing. 0: no change, 1: low, 2: high, 3: toggle.
- **MCPWM_GENO_A_DTEA**: Action on PWMOA triggered by event TEA when timer decreasing. 0: no change, 1: low, 2: high, 3: toggle.
- **MCPWM_GENO_A_DTEB**: Action on PWMOA triggered by event TEB when timer decreasing. 0: no change, 1: low, 2: high, 3: toggle.
- **MCPWM_GENO_A_DTO**: Action on PWMOA triggered by event_t0 when timer decreasing. 0: no change, 1: low, 2: high, 3: toggle.
- **MCPWM_GENO_AD_T1**: Action on PWMOA triggered by event_t1 when timer decreasing. 0: no change, 1: low, 2: high, 3: toggle.
