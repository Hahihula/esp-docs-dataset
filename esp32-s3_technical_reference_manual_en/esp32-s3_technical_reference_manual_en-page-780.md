### Register Information:

#### **Register 15.75. PMS_EDMA_PMS_SPI3_REG (0x02C4)**
- **Description:** 
  - `PMS_EDMA_PMS_SPI3 ATTR2` and `PMS_EDMA_PMS_SPI3 ATTR1`
- **Bit Description:**
  - Bits [31, ..., 0]: Reserved
  - Bit [30]: PMS_EDMA_PMS_SPI3 ATTR2 (Configures SPI3's access to external SRAM Area0. For details, see Table 15.5-4.) (R/W)
  - Bit [29]: PMS_EDMA_PMS_SPI3 ATTR1 (Configures SPI3's access to external SRAM Area1. For details, see Table 15.5-4.) (R/W)

#### **Register 15.76. PMS_EDMA_PMS_UHClO_LOCK_REG (0x02C8)**
- **Description:**
  - `PMS_EDMA_PMS_UHClO_LOCK`
- **Bit Description:**
  - Bits [31, ..., 0]: Reserved
  - Bit [30]: PMS_EDMA_PMS_UHClO_LOCK (Set this bit to lock the register that configures UHCIO's access to external SRAM. (R/W))
