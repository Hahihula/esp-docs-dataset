When neither of the three UART controllers is active, RAM can enter low-power mode by setting `UART_MEMFORCE_PD`.

- **UARTn Tx_FIFO** is reset by setting `UART_TXFIFO_RST`.
- **UARTn Rx_FIFO** is reset by setting `UART_RXFIFO_RST`.

The "empty" signal threshold for Tx_FIFO is configured by setting `UART_TXFIFO_EMPTY_THRD`. When data stored in Tx_FIFO is less than `UART_TXFIFO_EMPTY_THRD`, a UART_TXFIFO EMPTY_INT interrupt is generated. The "full" signal threshold for Rx_FIFO is configured by setting `UART_RXFIFO_FULL_THRD`. When data stored in Rx_FIFO is equal to or greater than `UART_RXFIFO_FULL_THRD`, a UART_RXFIFO FULL_INT interrupt is generated.

In addition, when Rx_FIFO receives more data than its capacity, a `UART_RXFIFO_OVF_INT` interrupt is generated. TX FIFO and RX FIFO can be accessed via the APB bus or GDMA. Access via the APB bus is performed through register `UART_FIFO_REG`. You can put data into TX FIFO by writing `UART_RXFIFO_RD_BYTE`, and get data in RX FIFO by reading this exact same field.

For access via GDMA, please refer to Section 26.4.11

26.4.3 Baud Rate Generation and Detection

**Subsection Subtitle:**
26.4.3.1 Baud Rate Generation

Before a UART controller sends or receives data, the baud rate should be configured by setting corresponding registers.

The baud rate generator of a UART controller functions by dividing the input clock source. It can divide the clock source by a fractional amount. The divisor is configured by `UART_CLKDIV_REG: UART_CLKDIV` for the integer part and `UART_CLKDIV_FRA` for the fractional part. When using the 80 MHz input clock, the UART controller supports a maximum baud rate of 5 Mbaud.

The divisor of the baud rate is equal to:

\[ \text{UART_CLKDIV} + \frac{\text{UART_CLKDIV_FRA}}{16} \]

meaning that the final baud rate is equal to

\[ \frac{\text{INPUT_FREQ}}{\text{UART_CLKDIV} + \frac{\text{UART_CLKDIV_FRA}}{16}} \]

where `INPUT_FREQ` is the frequency of UART Core's source clock. For example, if `UART_CLKDIV = 694` and `UART_CLKDIV_FRA = 7`, then the divisor value is

\[ 694 + \frac{7}{16} = 694.4375 \]

When `UART_CLKDIV_FRA` is zero, the baud rate generator is an integer clock divider where an output pulse is generated every `UART_CLKDIV` input pulses.

When `UART_CLKDIV_FRA` is not zero, the divisor is fractional and the output baud rate clock pulses are not strictly uniform. As shown in Figure 26.4-2, for every 16 output pulses, the frequency of some pulses is

\[ \frac{\text{INPUT_FREQ}}{\left(\text{UART_CLKDIV} + 1\right)} \]

and the frequency of other pulses is `INPUT_FREQ/UART_CLKDIV`. A total of `UART_CLKDIV_FRA` output pulses are generated by dividing `(UART_CLKDIV + 1)` input pulses, and the remaining (16 - `UART_CLKDIV_FRA`) output pulses are generated by dividing `UART_CLKDIV` input pulses.
