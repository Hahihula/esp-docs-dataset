Register 34.59. LP_I2C_COMD1_REG (0x005C)

LP_I2C_COMMAND1_DONE Represents whether command 1 is done in I2C Master mode.

LP_I2C_COMMAND1 Configures command 1.
See details in LP_I2C_COMMANDO. (R/W)

LP_I2C_COMMAND1_DONE
0: Not done
1: Done
(R/W/SS)
