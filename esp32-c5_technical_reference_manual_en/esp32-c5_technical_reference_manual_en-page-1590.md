```markdown
Register 41.26. MCPWM_CAP_CHn_REG (n: 0-2) (0x00FC+0x4*n)

MCPWM_CAPn_VALUE Represents value of last capture on CAPn. (RO)
```

```markdown
Register 41.27. MCPWM_CAP_STATUS_REG (0x0108)

MCPWM_CAPn_EDGE Represents the edge of the last capture trigger on channel n.
0: Rising edge
1: Falling edge
(RO)
```
