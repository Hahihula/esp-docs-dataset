Register 11.74. INTMTX_COREO_SRC_PASS_IN_SEC_STATUS_0_REG (0x015C)

INTMTX_COREO_INT_SRC_PASS_IN_SEC_STATUS_0 Represents whether the INTMTX sources numbered from 0 ~ 31 are configured for delegated interrupts. Each bit represents the configuration status of one INTMTX source.
- 0: The corresponding INTMTX source is not configured for delegation.
- 1: The corresponding INTMTX source is configured for delegation.
(RO)

Register 11.75. INTMTX_COREO_SRC_PASS_IN_SEC_STATUS_1_REG (0x0160)

INTMTX_COREO_INT_SRC_PASS_IN_SEC_STATUS_1 Represents whether the INTMTX sources numbered from 32 ~ 63 are configured for delegated interrupts. Each bit represents the configuration status of one INTMTX source.
- 0: The corresponding INTMTX source is not configured for delegation.
- 1: The corresponding INTMTX source is configured for delegation.
(RO)
