USB_SERIAL_JTAG_IN_EP1_WR_ADDR   Represents write data address of IN endpoint 1. (RO)
USB_SERIAL_JTAG_IN_EP1_RD_ADDR   Represents read data address of IN endpoint 1. (RO)
