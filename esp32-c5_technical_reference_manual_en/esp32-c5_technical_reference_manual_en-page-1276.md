Register 34.63. LP_I2C_COMD5_REG (0x006C)

LP_I2C_COMMAND5 Configures command 5. See details in LP_I2C_COMMANDO. (R/W)

LP_I2C_COMMAND5_DONE Represents whether command 5 is done in I2C Master mode.
    0: Not done
    1: Done
    (R/W/SS)
