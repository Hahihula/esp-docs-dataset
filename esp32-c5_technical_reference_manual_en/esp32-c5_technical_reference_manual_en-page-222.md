```markdown
Register 5.28. AHB_DMA_WEIGHT_EN_REG (0x0400)
```

| Bit Field | Description |
|-----------|-------------|
| `AHB_DMA_WEIGHT_EN` | Configures whether to enable weight arbitration.<br>0: Disable<br>1: Enable<br>(R/W) |
