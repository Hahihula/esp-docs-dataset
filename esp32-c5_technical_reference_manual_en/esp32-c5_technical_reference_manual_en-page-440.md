```markdown
## Register 9.60. PCR_ASSIST_CONF_REG (0x0100)

PCR_ASSIST_CLK_EN Configures whether or not to enable Debug Assistant clock.
- O: Not enable
- 1: Enable
(R/W)

PCR_ASSIST_RST_EN Configures whether or not to reset Debug Assistant.
- O: Not reset
- 1: Reset
(R/W)
```
