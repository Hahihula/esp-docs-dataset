(RO)\ndmode This is set to 1 if a trigger is being used by the debugger.\nO: Both Debug and M mode can write the tdata1 and tdata2 registers at the selected tselect.\n1: Only Debug Mode can write the tdata1 and tdata2 registers at the selected tselect.
