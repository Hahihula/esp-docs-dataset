**Title:**
10 Physical Dimensions

**Subtitle:**
10.2 Dimensions of External Antenna Connector

**Body Text:**
ESP32-S3-MINI-1U uses the third generation external antenna connector as shown in Figure 10-3 *Dimensions of External Antenna Connector*. This connector is compatible with the following connectors:

- W.FL Series connector from Hirose
- MHF III connector from I-PHIX
- AMC connector from Amphenol

**Figure Caption:**
Figure 10-3. Dimensions of External Antenna Connector

**Additional Information in Figure Description (below diagram):**
The external antenna used for ESP32-S3-MINI-1U during certification testing is the third generation monopole antenna, with material code TFPD08H10060011.

The module does not include an external antenna upon shipment. If needed, select a suitable external antenna based on the product’s usage environment and performance requirements.

It is recommended to select an antenna that meets the following requirements:
- 2.4 GHz band
- 50 Ω impedance
