**Title:**
Product Overview

**Body Text:**
ESP32-C3 is a low-power and highly-integrated MCU-based solution that supports 2.4 GHz Wi-Fi and Bluetooth® Low Energy (Bluetooth LE).

The functional block diagram of the SoC is shown below.

**Image Description - Block Diagram Title:** 
Espressif ESP32-C3 Wi-Fi + Bluetooth® Low Energy SoC

**Block Diagram Sections:**
1. **CPU and Memory**
   - RISC-V 32-bit Microprocessor
   - Cache (SRAM)
   - JTAG, ROM
   
2. **RF Wireless Digital Circuits**
   - External Wi-Fi MAC Baseband Switch
   - Fast RC Oscillator Bluetooth LE Link Controller

3. **Security**
   - SHA, RSA, AES, RNG
   - eFuse Controller
   - HMAC (Digital Signature)
   - Temperature Sensor
  
4. **Peripherals**
   - GDMA RMT General-purpose Timers
   - SPI0/1, SPI2 DIG ADC Sensors
   - I2C, I2S LED PWM USB Serial/JTAG Secure Boot Flash Encryption

5. **RTC**
   - RTC Timer Memory PMU (Power Management Unit)
   - World Debug Controller Assistant Super Watchdog Brownout Detector

**Subtitle: Power consumption**

- Normal 
- Low power consumption components capable of working in Deep-sleep mode
