**Register Information:**
- Register Name: RTC_CNTL_INT_ENA_REG (0x003C)
- Binary representation of the register bits is shown, with each bit labeled from right to left.

**Bit Labels and Descriptions:**

1. **RTC_CNTL_MAIN_TIMER_INT_ENA**: The interrupt enable bit for the RTC_CNTL_MAIN_TIMER_INT interrupt.
   - Access type: (R/W)

2. **RTC_CNTL_BROWN_OUT_INT_ENA**: The interrupt enable bit for the RTC_CNTL_BROWN_OUT_INT interrupt.
   - Access type: (R/W)

3. **RTC_CNTL_TOUCH_INT_ENA**: The interrupt enable bit for the RTC_CNTL TOUCH INT interrupt.
   - Access type: (R/W)

4. **RTC_CNTL_ULP_CP_INT_ENA**: The interrupt enable bit for the RTC_CNTL ULP CP INT interrupt.
   - Access type: (R/W)

5. **RTC_CNTL_TIME_VALID_INTE**: The interrupt enable bit for the RTC_CNTL TIME VALID INT interrupt.
   - Access type: (R/W)

6. **RTC_CNTL_WDT_INT_ENA**: The interrupt enable bit for the RTC_CNTL WDT INT interrupt.
   - Access type: (R/W)

7. **RTC_CNTL_SDIO_IDLE_INT_ENA**: The interrupt enable bit for the RTC_CNTL SDIO IDLE INT interrupt.
   - Access type: (R/W)

8. **RTC_CNTL_SLP_REJECT_INT_ENA**: The interrupt enable bit for the RTC_CNTL SLP REJECT INT interrupt.
   - Access type: (R/W)

9. **RTC_CNTL_SLP_WAKEUP_INT_ENA**: The interrupt enable bit for the RTC_CNTL SLEEP WAKEUP INT interrupt.
   - Access type: (R/W)
