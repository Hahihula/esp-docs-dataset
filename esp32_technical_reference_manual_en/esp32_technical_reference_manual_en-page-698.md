**Chapter Title:**
Chapter 29 Motor Control PWM (MCPWM)

**Register Information:**
- Register Name: PWM_GEN1_FORCEREG (0x0084)
- Bit Positions and Values:
  - 31 to 5 bits are reserved.
  - 0x20 is the reset value.

**Field Descriptions with Values Indicated by Bits in Binary Format:**

1. **PWM_GEN1_B_NCIFORCE_MODE**
   - Description: Non-continuous immediate software-force mode for PWM1B
   - Possible States:
     - 0: disabled (R/W)
     - 1: low force event trigger when bit2 is set to TEA; 
     - 2: high force event trigger;
     - 3: disabled

2. **PWM_GEN1_B_CNTUFORCE_MODE**
   - Description: Continuous software-force mode for PWM1B
   - Possible States:
     - 0: disabled (R/W)
     - 1: low, when bit5 is set to TEA; 
     - 2: high;
     - 3: disabled

3. **PWM_GEN1_A_NCIFORCE_MODE**
   - Description: Non-continuous immediate software-force mode for PWM1A
   - Possible States:
     - 0: disabled (R/W)
     - 1: low force event trigger when bit2 is set to TEA; 
     - 2: high;
     - 3: disabled

4. **PWM_GEN1_A_CNTUFORCE_MODE**
   - Description: Continuous software-force mode for PWM1A
   - Possible States:
     - 0: disabled (R/W)
     - 1: low, when bit5 is set to TEA; 
     - 2: high;
     - 3: disabled

5. **PWM_GEN1_A_CNTUFORCE_UPMETHOD**
   - Description: Updating method for continuous software force of PWM generator
   - Possible States:
     - When all bits are set to O, immediately.
     - bit0 is set to TEZ; 
     - when bit1 is set to TEP;
     - when bit2 is set to TEA;
     - when bit3 is set to 1: TEB;
     - when bit4 is set to sync;
     - when bit5 is set to disable update.
   - Note on TEA/B and register A/B:
     - An event generated by the timer’s value equals that of register A/B (R/W)
