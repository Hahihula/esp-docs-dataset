**Section Header - Register 6.8:**
- **Title:** Register 6.8. GPIO_ENABLE_W1TS_REG (0x0024)
- **Description:** 
  - **Text:** "Reset"
  - **Binary Representation and Description:** "GPIO_31 output enable set register. For every bit that is 1 in the value written here, the corresponding bit in GPIO_ENABLE will be set." (WO)

---

**Section Header - Register 6.9:**
- **Title:** Register 6.9. GPIO_ENABLE_W1TC_REG (0x0028)
- **Description:** 
  - **Text:** "Reset"
  - **Binary Representation and Description:** "GPIO_31 output enable clear register. For every bit that is 1 in the value written here, the corresponding bit in GPIO_ENABLE will be cleared." (WO)
