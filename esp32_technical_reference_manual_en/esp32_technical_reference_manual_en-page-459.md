**Title:**
Chapter 23 Pulse Count Controller (PCNT)

**Subtitles and Sections:**

1. **Register 23.7. PCNT_INT_ENA_REG (0x0088)**
   - Description:
     ```
     PCNT_CNT_THR_EVENT_UN_INT_ENA The interrupt enable bit for the PCNT_CNT_THR_EVENT_Un_INT interrupt.
     ```
   - Binary representation of register bits: 
     ```
     31 (reserved)
     8 7 6 5 4 3 2 1 0
     0x00000000
     ```

2. **Register 23.8. PCNT_INT_CLR_REG (0x008c)**
   - Description:
     ```
     PCNT_CNT_THR_EVENT_UN_INT_CLR Set this bit to clear the PCNT_CNT_THR_EVENT_Un_INT interrupt.
     ```
   - Binary representation of register bits: 
     ```
     31 (reserved)
     8 7 6 5 4 3 2 1 0
     0x00000000
     ```
