**Register Information:**
- **Register Name:** SLCOHOST_TOKEN_RDATA (0x44)
- **Description:** HOSTREG_SLCO_TOKEN1 The accumulated number of Slave's receiving buffers. (RO)

**Bitfield Description:**
- 31 - reserved
- 28, 27, 16, 15 - reserved
- 0 - Reset

**Hexadecimal Values in Bitfield:**
- Ox000 at positions corresponding to bits 31 and others.
- Ox000 for the reset bit.
