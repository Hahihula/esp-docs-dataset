**Interrupt Enable Bits Description:**

- **UART_TXFIFO_EMPTY_INTENA**
  - The interrupt enable bit for the UART_TXFIFO_EMPTY_INT interrupt.
  - Access Mode: Read/Write

- **UART_RXFIFO_FULL_INTENA**
  - The interrupt enable bit for the UART_RXFIFO_FULL_INT interrupt.
  - Access Mode: Read/Write
