### Subtitle: PCB Land Pattern

This section provides the following resources for your reference:

- **Figures**: For recommended PCB land patterns with all dimensions needed for PCB design. See Figure 11-1 ESP32-C3-WROOM-02 Recommended PCB Land Pattern and Figure 11-2 ESP32-C3-WROOM-02U Recommended PCB Land Pattern.
  
- Source files of the recommended PCB land patterns to measure dimensions not covered in Figure 11-1 are available. You can view these source files for ESP32-C3-WROOM-02 and ESP32-C3-WROOM-02U with Autodesk Viewer.

- **3D models**: Download the 3D model file in .STEP format from [here](#). Please ensure that you have a compatible browser to download this. Some browsers might add .txt extension automatically.
  
**Diagram Description:**
The diagram is labeled "Figure 11-1 ESP32-C3-WROOM-02 Recommended PCB Land Pattern" and shows dimensions in millimeters (mm) for various components such as the antenna area, thermal pad via size, copper layer thicknesses, etc. The unit of measurement provided at the top left corner indicates that all measurements are given in mm.
