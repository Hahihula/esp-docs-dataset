The external antenna used for ESP32-C3-WROOM-02U during certification testing is:
- Certification except FCC: First generation monopole antenna, with material code TFPD05H08750011

FCC: Glue stick antenna, with material code TFPD05H09170011

The module does not include an external antenna upon shipment. If needed, select a suitable external antenna based on the product’s usage environment and performance requirements.

It is recommended to select an antenna that meets the following requirements:
- 2.4 GHz band
- 50 Ω impedance

The maximum gain does not exceed the gain of the antenna used for certification, which is:
- Certification except FCC: 2.33 dBi
- FCC: 1.57 dBi
