```markdown
Register 11.2. PMU_HP_ACTIVE_ICG_HP_FUNC_REG (0x0004)

PMU_HP_ACTIVE_DIG_ICG_FUNC_EN Configures whether to enable HP system peripherals' function clock in HP_ACTIVE state. For detailed configuration please see Chapter 7 Reset and Clock > Table 7.2-8.

O: Disable
1: Enable
(R/W)
```

```markdown
Register 11.3. PMU_HP_ACTIVE_ICG_HP_APB_REG (0x0008)

PMU_HP_ACTIVE_DIG_ICG_APB_EN Configures whether to enable HP system peripherals' APB clock in HP_ACTIVE state. For detailed configuration please see Chapter 7 Reset and Clock > Table 7.2-7.

O: Disable
1: Enable
(R/W)
```
