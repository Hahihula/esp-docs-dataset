Register 2.9. TRACE_TRIGGER_REG (0x0020)

| Bit | Field Name           | Description                                                                 |
|-----|----------------------|-----------------------------------------------------------------------------|
| 31  |                      | (reserved)                                                                  |
| 4   | TRACE_RESTART_ENA    | Configures whether to enable automatic restart.<br>0: Disable<br>1: Enable<br>(R/W) |
| 3   | TRACE_TRIGGER_OFF    | Configures whether to disable the encoder.<br>0: Invalid<br>1: Disable<br>(WT) |
| 2   | TRACE_MEM_LOOP       | Configures the memory writing mode.<br>0: Non-loop mode<br>1: Loop mode<br>(R/W) |
| 1   | TRACE_TRIGGER_ON     | Configures whether to enable the encoder.<br>0: Invalid<br>1: Enable<br>(WT)    |
| 0   |                      | Reset                                                                       |
