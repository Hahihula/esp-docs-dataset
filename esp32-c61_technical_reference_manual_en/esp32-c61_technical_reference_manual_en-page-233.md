Register 5.10. EFUSE_RD_MAC_SYS1_REG (0x0048)

EFUSE_MAC_1 Represents high 16-bit of MAC address. (RO)
EFUSE_MAC_EXT Represents the extended bits of MAC address. (RO)


Register 5.11. EFUSE_RD_MAC_SYS2_REG (0x004C)

EFUSE_MAC_RESERVED_0 Reserved (RO)
EFUSE_MAC_RESERVED_1 Reserved (RO)


Register 5.12. EFUSE_RD_MAC_SYS3_REG (0x0050)

EFUSE_MAC_RESERVED_2 Reserved (RO)
EFUSE_SYS_DATA_PARTO_0 Represents the first 14 bits of zeroth part of system data. (RO)
