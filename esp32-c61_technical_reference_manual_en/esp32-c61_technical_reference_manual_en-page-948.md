Register 26.16. SPI_DOUT_MODE_REG (0x002C)

Continued from the previous page...

SPI_DOUT6_MODE Configures whether the output signal DOUT6 is delayed by one SPI module clock cycle at its falling edge.
O: No delay.
1: Delayed by one SPI module clock cycle (falling edge).
Can be configured in CONF state.
(HRO)

SPI_DOUT7_MODE Configures whether the output signal DOUT7 is delayed by one SPI module clock cycle at its falling edge.
O: No delay.
1: Delayed by one SPI module clock cycle (falling edge).
Can be configured in CONF state.
(HRO)

SPI_D_DQS_MODE Configures whether the SPI_DQS output signal is delayed by one SPI module clock cycle at its falling edge.
O: No delay.
1: Delayed by one SPI module clock cycle (falling edge).
Can be configured in CONF state.
(HRO)
