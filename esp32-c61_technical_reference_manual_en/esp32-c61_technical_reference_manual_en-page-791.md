```markdown
Register 21.5. SHA_DMA_CONTINUE_REG (0x0020)
```


```markdown
Register 21.7. SHA_INT_ENA_REG (0x0028)

SHA_INTERRUPT_ENA   Write 1 to enable DMA-SHA interrupt. (R/W)
```
