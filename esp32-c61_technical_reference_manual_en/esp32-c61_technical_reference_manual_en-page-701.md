Chapter 16 Permission Control (PMS)

Register 16.43. CPU_APM_MO_STATUS_CLR_REG (0x00CC)

CPU_APM_MO_EXCEPTION_STATUS_CLR Write 1 to clear exception status. (WT)

Register 16.44. CPU_APM_MO_EXCEPTION_INFOO_REG (0x00DO)

CPU_APM_MO_EXCEPTION_REGION Represents the region where an exception occurs. (RO)
CPU_APM_MO_EXCEPTION_MODE Represents the master's security mode when an exception oc-
curs. (RO)
CPU_APM_MO_EXCEPTION_ID Represents master ID when an exception occurs. (RO)
