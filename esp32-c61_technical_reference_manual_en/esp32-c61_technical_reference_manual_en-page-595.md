Register 11.107. PAU_INT_CLR_REG (0x0038)

PAU_DONE_INT_CLR Write 1 to clear the backup done interrupt. (WT)
PAU_ERROR_INT_CLR Write 1 to clear the error interrupt. (WT)

Register 11.108. PAU_INT_ST_REG (0x003C)

PAU_DONE_INT_ST Represents the backup completion status. (RO)
PAU_ERROR_INT_ST Represents the error status. (RO)

Register 11.109. PAU_DATE_REG (0x03FC)

PAU_DATE Version control register. (R/W)
