Register 9.53. INTMTX_COREO_INT_STATUS_O_REG (0x0108)

| Bit | Field Name           | Description                                                                 |
|-----|----------------------|-----------------------------------------------------------------------------|
| 31  | INTMTX_COREO_INT_STATUS_O | Represents the status of the INTMTX sources numbered from 0 ~ 31. Each bit corresponds to one INTMTX source.<br>0: The corresponding INTMTX source triggered an interrupt<br>1: No interrupt triggered (RO) |

Register 9.54. INTMTX_COREO_INT_STATUS_1_REG (0x0144)

| Bit | Field Name           | Description                                                                 |
|-----|----------------------|-----------------------------------------------------------------------------|
| 31  | INTMTX_COREO_INT_STATUS_1 | Represents the status of the INTMTX sources numbered from 32 ~ 63. Each bit corresponds to one INTMTX source.<br>0: The corresponding INTMTX source triggered an interrupt<br>1: No INTMTX triggered (RO) |
