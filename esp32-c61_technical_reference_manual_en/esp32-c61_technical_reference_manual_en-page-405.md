Register 9.57. INTMTX_COREO_SRC_PASS_IN_SEC_STATUS_1_REG (0x0118)

INTMTX_COREO_INT_SRC_PASS_IN_SEC_STATUS_1 Represents whether the INTMTX sources numbered from 31 ~ 63 are configured for delegated interrupts. Each bit represents the configuration status of one INTMTX source.
- 0: The corresponding INTMTX source is not configured for delegation.
- 1: The corresponding INTMTX source is configured for delegation.
(RO)

Register 9.58. INTMTX_COREO_SRC_PASS_IN_SEC_STATUS_2_REG (0x011C)

INTMTX_COREO_INT_SRC_PASS_IN_SEC_STATUS_2 Represents whether the INTMTX sources numbered from 64 ~ 65 are configured for delegated interrupts. Each bit represents the configuration status of one INTMTX source.
- 0: The corresponding INTMTX source is not configured for delegation.
- 1: The corresponding INTMTX source is configured for delegation.
(RO)
