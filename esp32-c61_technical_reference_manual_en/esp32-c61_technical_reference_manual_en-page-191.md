Register 3.34. AHB_DMA_IN_DSCR_CHn_REG (n: 0-1) (0x0090+0xC0*n)

AHB_DMA_INLINK_DSCR_CHn Represents the address of the next receive descriptor x+1 pointed by the current receive descriptor that is pre-read. (RO)

Register 3.35. AHB_DMA_IN_DSCR_BFO_CHn_REG (n: 0-1) (0x0094+0xC0*n)

AHB_DMA_INLINK_DSCR_BFO_CHn Represents the address of the current receive descriptor x that is pre-read. (RO)

Register 3.36. AHB_DMA_IN_DSCR_BF1_CHn_REG (n: 0-1) (0x0098+0xC0*n)

AHB_DMA_INLINK_DSCR_BF1_CHn Represents the address of the previous receive descriptor x-1 that is pre-read. (RO)
