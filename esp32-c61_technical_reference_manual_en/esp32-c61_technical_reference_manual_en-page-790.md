## 21.6 Registers\n\nThe addresses in this section are relative to the SHA accelerator base address provided in Table 4.3-2 in Chapter 4 System and Memory.\n\n### Register 21.1. SHA_START_REG (0x0010)\n\n```\n31                                 1          0\n+-----------------------------------------------+\n| (reserved)                                | SHA_START |\n+-----------------------------------------------+\n| 0 0 ... 0 0 0 0                        Reset |\n+-----------------------------------------------+\n```\n\nSHA_START Write 1 to start Typical SHA calculation. (WO)\n\n### Register 21.2. SHA_CONTINUE_REG (0x0014)\n\n```\n31                                 1          0\n+-----------------------------------------------+\n| (reserved)                                | SHA_CONTINUE |\n+-----------------------------------------------+\n| 0 0 ... 0 0 0 0                        Reset |\n+-----------------------------------------------+\n```\n\nSHA_CONTINUE Write 1 to continue Typical SHA calculation. (WO)\n\n### Register 21.3. SHA_BUSY_REG (0x0018)\n\n```\n31                                 1          0\n+-----------------------------------------------+\n| (reserved)                                | SHA_BUSY_STATE |\n+-----------------------------------------------+\n| 0 0 ... 0 0 0 0                        Reset |\n+-----------------------------------------------+\n```\n\nSHA_BUSY_STATE Represents the states of SHA accelerator.\n- 0: idle\n- 1: busy\n(RO)\n```
