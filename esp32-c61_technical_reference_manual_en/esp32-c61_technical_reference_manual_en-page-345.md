Register 7.9. PCR_UART2_PD_CTRL_REG (0x0020)

PCR_UART2_MEM_FORCE_PU   Configures whether or not to force power up UART2 memory.
O: Not force power up UART2 memory
1: Force power up UART2 memory
(R/W)

PCR_UART2_MEM_FORCE_PD   Configures whether or not to force power down UART2 memory.
O: Not force power down UART2 memory
1: Force power down UART2 memory
(R/W)

Register 7.10. PCR_I2C_CONF_REG (0x002C)

PCR_I2C_CLK_EN   Configures whether or not to enable APB_CLK for I2C.
O: Not enable
1: Enable
(R/W)

PCR_I2C_RST_EN   Configures whether or not to reset I2C.
O: Not reset
1: Reset
(R/W)
