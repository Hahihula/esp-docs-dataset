```markdown
SPI_DIN4_NUM Configures the number of SPI module clock cycles by which the input signal DIN4 is delayed.
- O: Delayed by 1 cycle.
- 1: Delayed by 2 cycles.
...
Can be configured in CONF state.
(HRO)
```
