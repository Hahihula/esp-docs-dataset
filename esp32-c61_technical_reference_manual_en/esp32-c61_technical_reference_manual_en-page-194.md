Register 3.40. AHB_DMA_OUT_EOF_BFR_DES_ADDR_CHn_REG (n: 0-1) (0x00EC+0xC0*n)

AHB_DMA_OUT_EOF_BFR_DES_ADDR_CHn   Represents the address of the transmit descriptor before the last transmit descriptor. (RO)


Register 3.41. AHB_DMA_OUT_DSCR_CHn_REG (n: 0-1) (0x00FO+0xC0*n)

AHB_DMA_OUTLINK_DSCR_CHn   Represents the address of the next transmit descriptor y+1 pointed by the current transmit descriptor that is pre-read. (RO)


Register 3.42. AHB_DMA_OUT_DSCR_BFO_CHn_REG (n: 0-1) (0x00F4+0xC0*n)

AHB_DMA_OUTLINK_DSCR_BFO_CHn   Represents the address of the current transmit descriptor y that is pre-read. (RO)
