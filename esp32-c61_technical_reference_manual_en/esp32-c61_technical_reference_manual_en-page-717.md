Register 17.11. LP_PERI_BUS_TIMEOUT_UID_REG (0x0018)

LP_PERI_BUS_TIMEOUT_UID Represents the master ID[4:0] and master permission[6:5] when trigger timeout. For details, see Chapter 16 Permission Control (PMS). This register will be cleared after the interrupt is cleared. (WTC)

Register 17.12. HP_SYSTEM_DATE_REG (0x03FC)

HP_SYSTEM_DATE Version control register. (R/W)
