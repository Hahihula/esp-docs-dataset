Register 11.15. PMU_HP_MODEM_ICG_HP_FUNC_REG (0x0038)

PMU_HP_MODEM_DIG_ICG_FUNC_EN

PMU_HP_MODEM_DIG_ICG_FUNC_EN Configures whether to enable HP system peripherals' function clock in HP_MODEM state. For detailed configuration please see Chapter 7 Reset and Clock > Table 7.2-8.

0: Disable
1: Enable
(R/W)

Register 11.16. PMU_HP_MODEM_ICG_HP_APB_REG (0x003C)

PMU_HP_MODEM_DIG_ICG_APB_EN

PMU_HP_MODEM_DIG_ICG_APB_EN Configures whether to enable HP system peripherals' APB clock in HP_MODEM state. For detailed configuration please see Chapter 7 Reset and Clock > Table 7.2-7.

0: Disable
1: Enable
(R/W)
