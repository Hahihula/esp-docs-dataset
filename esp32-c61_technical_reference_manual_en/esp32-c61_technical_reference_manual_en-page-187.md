## Register 3.24. AHB_DMA_INTR_MEM_START_ADDR_REG (0x03C4)

```
AHB_DMA_ACCESS_INTR_MEM_START_ADDR   Configures the start address of accessible address space. (R/W)
```

## Register 3.25. AHB_DMA_INTR_MEM_END_ADDR_REG (0x03C8)

```
AHB_DMA_ACCESS_INTR_MEM_END_ADDR   Configures the end address of accessible address space. (R/W)
```

## Register 3.26. AHB_DMA_ARB_TIMEOUT_TX_REG (0x03CC)

```
AHB_DMA_ARB_TIMEOUT_TX   Configures the time slot for TX. Measurement unit: AHB bus clock cycle. (R/W)
```
