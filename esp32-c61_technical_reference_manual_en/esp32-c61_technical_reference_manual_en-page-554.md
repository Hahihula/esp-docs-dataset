Register 11.44. PMU_LP_SLEEP_LP_REGULATORO_REG (0x00B4)

PMU_LP_SLEEP_LP_REGULATOR_SLP_XPD Configures whether to enable the secondary LP regulator in LP_SLEEP state.
    0: Disable
    1: Enable
    (R/W)

PMU_LP_SLEEP_LP_REGULATOR_XPD Configures whether to enable the main LP regulator in LP_SLEEP state.
    0: Disable
    1: Enable
    (R/W)

PMU_LP_SLEEP_LP_REGULATOR_SLP_DBIAS Configures the DREG value of the secondary LP regulator in LP_SLEEP state, adjusting its output voltage. (R/W)

PMU_LP_SLEEP_LP_REGULATOR_DBIAS Configures the DREG value of the main LP regulator in LP_SLEEP state, adjusting its output voltage. (R/W)
