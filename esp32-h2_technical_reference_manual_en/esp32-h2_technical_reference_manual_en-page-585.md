In this working mode, the plaintext and ciphertext is written and read via CPU directly.\n\n- **DMA-AES Working Mode:**\n  - Supports encryption and decryption using cryptographic keys of 128 and 256 bits, specified in [NIST FIPS 197](#);\n  - Supports block cipher modes ECB, CBC, OFB, CTR, CFB8, and CFB128 under [NIST SP 800-38A](#). In this working mode, the plaintext and ciphertext are written and read via DMA. An interrupt will be generated when operation completes.\n\nUsers can choose the working mode for AES accelerator by configuring the `AES_DMA_ENABLE_REG` register according to Table 19.4-1 below.\n\nTable 19.4-1.
