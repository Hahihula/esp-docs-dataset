

```markdown
Register 13.5. TIMG_TOALARMLO_REG (0x0010)

TIMG_TO_ALARM_LO Configures the low 32 bits of Timer 0 alarm trigger time-base counter value.
Valid only when TIMG_TO_ALARM_EN is 1.
Measurement unit: TO_clk
(R/W)
```

```markdown
Register 13.6. TIMG_TOALARMHI_REG (0x0014)

TIMG_TO_ALARM_HI Configures the high 22 bits of Timer 0 alarm trigger time-base counter value.
Valid only when TIMG_TO_ALARM_EN is 1.
Measurement unit: TO_clk
(R/W)
```

```markdown
Register 13.7. TIMG_TOLOADLO_REG (0x0018)

TIMG_TO_LOAD_LO Configures low 32 bits of the value that a reload will load onto Timer 0 time-
base counter.
Measurement unit: TO_clk
(R/W)
```
