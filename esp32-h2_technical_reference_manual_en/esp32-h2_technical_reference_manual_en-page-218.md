The other output signals can only be routed to pins via GPIO matrix.\n5. There are 19 outputs (corresponding to GPIO pin X: 0 ~ 5, 8 ~ 14, 22 ~ 27) from GPIO matrix to IO MUX.\n\nFigure 6.3-2 shows the internal structure of a pad, which is an electrical interface between the chip logic and the GPIO pin. The structure is applicable to all 19 GPIO pins and can be controlled using IE, OE, WPU, and WPD signals.
