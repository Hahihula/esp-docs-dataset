```markdown
Register 30.32. I2C_COMD7_REG (0x0074)

I2C_COMMAND7 Configures command 7. See details in I2C_COMDO_REG. (R/W)

I2C_COMMAND7_DONE Represents whether command 7 is done in I2C Master mode.
0: Not done
1: Done
(R/W/SS)
```
