Chapter 30 I2C Controller (I2C)

Register 30.9. I2C_SCL_ST_TIME_OUT_REG (0x0078)

I2C_SCL_ST_TO_I2C Configures the threshold value of SCL_FSM state unchanged period. It should be no more than 23.
Measurement unit: I2C_SCLK
(R/W)

Register 30.10. I2C_SCL_MAIN_ST_TIME_OUT_REG (0x007C)

I2C_SCL_MAIN_ST_TO_I2C Configures the threshold value of SCL_MAIN_FSM state unchanged period. It should be no more than 23.
Measurement unit: I2C_SCLK
(R/W)
