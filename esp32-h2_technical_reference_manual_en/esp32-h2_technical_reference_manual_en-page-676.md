## 25.8 Registers

The addresses in this section are relative to the ECDSA base address provided in Table 4.3-2 in Chapter 4 System and Memory.

For how to program reserved fields, please refer to Section Programming Reserved Register Field.

Register 25.1. ECDSA_CONF_REG (0x0004)

| Bit | Name                     | Description                                                                 |
|-----|--------------------------|-----------------------------------------------------------------------------|
| 31  |                          | (reserved)                                                                  |
| 3   | ECDSA_WORK_MODE          | Configures the working mode of ECDSA accelerator.<br>0: Signature Generation mode<br>1: Signature Verification mode<br>(R/W) |
| 2   | ECDSA_ECC_CURVE          | Configures the elliptic curve used.<br>0: P-192<br>1: P-256<br>(R/W)         |
| 1   | ECDSA_SOFTWARE_SET_K     | Configures how the parameter k is set.<br>0: automatically generated by TRNG<br>1: written by software<br>(R/W) |
| 0   | ECDSA_SOFTWARE_SET_Z     | Configures how the parameter z is set.<br>0: generated from SHA result<br>1: written by software<br>(R/W) |
