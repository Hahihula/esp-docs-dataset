Register 40.7. APB_SARADC_FILTER_CTRL0_REG (0x0028)

APB_SARADC_FILTER_CHANNEL1 Configures the filter channel for SAR ADC filter 1. (R/W)
APB_SARADC_FILTER_CHANNEL0 Configures the filter channel for SAR ADC filter 0. (R/W)
APB_SARADC_FILTER_RESET Configures whether to reset SAR ADC filter.
O: No effect
1: Reset
(R/W)

Register 40.8. APB_SARADC_SAR1DATA_STATUS_REG (0x002C)

APB_SARADC_DATA Stores SAR ADC conversion data in one-shot sampling mode. (RO)

Register 40.9. APB_SARADC_THRESO_CTRL_REG (0x0034)

APB_SARADC_THRESO_CHANNEL Configures the channel for SAR ADC monitor O. (R/W)
APB_SARADC_THRESO_HIGH Configures the high threshold for SAR ADC monitor O. (R/W)
APB_SARADC_THRESO_LOW Configures the low threshold for SAR ADC monitor O. (R/W)
