Each event corresponds to a pulse signal generated by the corresponding peripheral in its clock domain, while each task is mapped by the ETM to a pulse signal under its corresponding peripheral clock domain. The peripherals generating events, the Event Task Matrix, and peripherals receiving tasks are not necessarily running off the same clock and as such need to be synchronized. Therefore, there must be a minimum interval between two consecutive events to avoid event loss: to make sure the Event Task Matrix receives every event successfully, for peripherals generating event pulses, the interval between two consecutive pulses must be greater than one ETM clock cycle, namely `ceil(peripheral_clock_frequency / ETM_clock_frequency)` in the unit of peripheral clock cycles.\n\nFor example, assuming that event 1 generated by peripheral A is in the 96 MHz clock domain (PLL_F96M_CLK), and the ETM runs in the 32 MHz clock domain (AHB_CLK).
