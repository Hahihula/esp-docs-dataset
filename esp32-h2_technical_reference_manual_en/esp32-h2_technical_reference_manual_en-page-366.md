

```markdown
Register 9.61. INTPRI_COREO_CPU_INT_TYPE_REG (0x0004)

INTPRI_COREO_CPU_INT_TYPE Configures CPU interrupt type.

0: Level-triggered
1: Edge-triggered

For more information about how to use this register, see Chapter 1 ESP-RISC-V CPU > Section 1.6 Interrupt Controller.
(R/W)
```

Register 9.62. INTPRI_COREO_CPU_INT_EIP_STATUS_REG (0x0008)

INTPRI_COREO_CPU_INT_EIP_STATUS Represents the pending status of CPU interrupts. For more information about how to use this register, see Chapter 1 ESP-RISC-V CPU > Section 1.6 Interrupt Controller. (RO)
