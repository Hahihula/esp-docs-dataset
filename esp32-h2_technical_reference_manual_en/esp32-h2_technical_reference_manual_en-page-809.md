

```markdown\n# 29.11 Registers\nThe addresses in this section are relative to SPI base address provided in Table 4.3-2 in Chapter 4 System and Memory.\n\n### Register 29.1. SPI_CMD_REG (0x0000)\n\n| Bit | Description |\n|-----|-------------|\n| 31  | (reserved)  |\n| 30  | SPI_USR     |\n| 29  | SPI_UPDATE  |\n| 28  | (reserved)  |\n| ... | ...         |\n| 0   | Reset       |\n\n- **SPI_CONF_BITLEN**: Configures the SPI_CLK cycles of SPI CONF state. Unit: SPI_CLK clock cycle. Can be configured in CONF state. (R/W)\n- **SPI_UPDATE**: Configures whether or not to synchronize SPI registers from APB clock domain into SPI module clock domain. 0: Not synchronize; 1: Synchronize. This bit is only used in SPI master transfer. (WT)\n- **SPI_USR**: Configures whether or not to enable user-defined command. 0: Not enable; 1: Enable. An SPI operation will be triggered when the bit is set. This bit will be cleared once the operation is done. Can not be changed by CONF_buf. (R/W/SC)\n\n### Register 29.2. SPI_ADDR_REG (0x0004)\n\n| Bit | Description |\n|-----|-------------|\n| 31  | Reset       |\n\n- **SPI_USR_ADDR_VALUE**: Configures the address to slave. Can be configured in CONF state. (R/W)\n```
