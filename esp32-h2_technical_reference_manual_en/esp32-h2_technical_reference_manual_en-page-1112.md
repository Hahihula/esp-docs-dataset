Chapter 36 Motor Control PWM (MCPWM)

Register 36.20. MCPWM_GENO_FORCE_REG (0x004C)

Continued from the previous page...

MCPWM_GENO_B_NCIFORCE Configures whether or not to trigger a non-continuous immediate software-force event for PWMOB.
    O: No effect
    1: Trigger a force event
        (R/W)

MCPWM_GENO_B_NCIFORCE_MODE Configures non-continuous immediate software force mode for PWMOB. See details in MCPWM_GENO_A_NCIFORCE_MODE. (R/W)
