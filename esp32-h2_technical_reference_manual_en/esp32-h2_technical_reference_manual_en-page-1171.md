```markdown
Register 36.75. MCPWM_CLK_REG (0x0128)
```

| Bit | Description         |
|-----|---------------------|
| 31  | Reserved            |
| ... |                     |
| 0   | Reset               |

**MCPWM_CLK_EN** Configures whether or not to force the clock on.

- 0: No effect
- 1: Force the clock on  
(R/W)
