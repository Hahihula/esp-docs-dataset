# Bluetooth® AVRCP API

## Overview

AVRCP (Audio/Video Remote Control Profile) enables remote control of audio and video devices over Bluetooth, allowing users to manage playback (play, pause, next/previous track), adjust volume, and retrieve media metadata.

## Application Examples

- `bluetooth/bluedroid/classic_bt/avrcp_absolute_volume`{.interpreted-text role="example"} demonstrates how to implement Audio/Video Remote Control Profile to control absolute volume.
- `bluetooth/bluedroid/classic_bt/avrcp_ct_metadata`{.interpreted-text role="example"} demonstrates how to implement Audio/Video Remote Control Profile to get metadata.
- `bluetooth/bluedroid/classic_bt/avrcp_ct_cover_art`{.interpreted-text role="example"} demonstrates how to implement Audio/Video Remote Control Profile to get and display cover art image.
