# IEEE 802.15.4

`zh_CN:[中文]`{.interpreted-text role="link_to_translation"}

## Receive Handle Done

User must call the function `esp_ieee802154_receive_handle_done`{.interpreted-text role="cpp:func"} to notify 802.15.4 driver after the received frame is handled. Otherwise the frame buffer will not be freed for future use.
