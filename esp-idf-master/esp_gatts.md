## Application Examples

- `bluetooth/bluedroid/ble/gatt_server_service_table`{.interpreted-text role="example"} demonstrates how to create a GATT service using an attribute table, releasing the user from adding attributes individually.
- `bluetooth/bluedroid/ble/gatt_server`{.interpreted-text role="example"} demonstrates how to create a GATT service by adding attributes individually and then starts advertising so that a GATT client can connect and exchange data.
